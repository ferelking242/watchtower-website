## Was für eine Erweiterung ist

Es ist JavaScript, kein Plugin, das Sie kompilieren. Es weiß, wie man eine Website nach ihren Einträgen, ihren Suchergebnissen, ihren Kapiteln und ihren Videostreams fragt, und sie antwortet in der Form, die Watchtower versteht.

## Wie sie Sie erreichen

Erweiterungen werden in Repositorys gruppiert. Sie fügen ein Repository einmal hinzu und jede darin enthaltene Erweiterung kann über den Erweiterungsbildschirm installiert werden.

## Arten von Inhalten

Eine Erweiterung gibt an, wozu sie dient: Manga, Anime, Roman, Musik oder Spiel. Diese Deklaration entscheidet darüber, welcher Reader oder Player geöffnet wird, wenn Sie auf ein Ergebnis tippen.

## Updates und Entfernung

Erweiterungen werden aktualisiert und behalten ihre Einstellungen bei. Durch die Deinstallation wird nur die Erweiterung entfernt. Ihre Bibliothekseinträge bleiben bestehen und warten einfach darauf, dass eine Quelle sie erneut bereitstellt.

## Warum es dich interessieren sollte, wer es gemacht hat

Eine Erweiterung läuft in Watchtower, kann aber das Netzwerk erreichen und lesen, was Sie ihr geben. Installieren Sie aus vertrauenswürdigen Repositories und seien Sie bei unbekannten Dingen vorsichtig.

## Wenn eine Erweiterung nicht mehr funktioniert

Websites ändern sich und eine Quelle bricht mit ihnen. Dabei handelt es sich in der Regel um eine defekte Erweiterung, nicht um eine defekte App, und der Fix kommt als Update.

## Wenn eine Installation oder Aktualisierung fehlschlägt

Eine fehlgeschlagene Installation liegt fast immer daran, dass Android unbekannte Apps blockiert, und ein fehlgeschlagenes Update ist ein Download, der teilweise abgebrochen wurde. Lassen Sie Installationen über Ihren Dateimanager oder Browser zu, versuchen Sie es dann erneut und installieren Sie es von Grund auf neu, wenn die Datei abgeschnitten wurde.

## Kurzüberblick

- Erweiterungen sind JavaScript und werden in einer Sandbox innerhalb der App ausgeführt.
- Eine Erweiterung deckt eine Website ab.
- Durch die Installation und Aktualisierung wird Ihre Bibliothek niemals berührt.
- Eine Quelle, die plötzlich ausfällt, ist normalerweise eine Website-Änderung.
- Eine fehlgeschlagene Installation ist normalerweise Android, nicht die Erweiterung.

## Vertrag / Beispiel

```text
One extension  →  one website

Installed    ready to browse
Available    in a repository you added, not installed yet
Updates      a newer version exists

A repository  →  a list of extensions, hosted as one JSON file
```
