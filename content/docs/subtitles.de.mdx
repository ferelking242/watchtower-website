## Einen Titel auswählen

Wenn eine Episode mehrere Untertitelspuren enthält, werden diese im Untertitelblatt aufgeführt. Ihre Auswahl wird für diese Serie gespeichert, sodass Sie sie nur einmal auswählen können.

## Das Timing korrigieren

Eine Spur, die vor oder hinter dem Audio läuft, kann in kleinen Schritten verschoben werden, bis sie ausgerichtet ist. Der Offset wird gespeichert, sodass der Fix den Neustart der App überlebt.

## Styling

Für Textuntertitel gelten Schriftart, Größe, Farbe, Umriss und Hintergrund. Diese Einstellungen wirken sich nicht auf das Video aus und Sie können problemlos mitten in der Episode experimentieren.

## Ihre eigenen Dateien

Platzieren Sie eine Untertiteldatei neben einer lokalen Episode mit passendem Namen und der Player lädt sie automatisch, ohne dass eine Einstellung geändert werden muss.

## In das Bild eingebrannte Untertitel

Einige Untertitel bestehen eher aus Bildern als aus Text. Sie können nicht neu gestaltet, sondern nur neu positioniert oder in der Größe geändert werden, da der Stil Teil des Bildes selbst ist.

## Wenn Untertitel nicht angezeigt werden

Überprüfen Sie zuerst das Untertitelblatt: Die Quelle bietet möglicherweise keine an, oder der Dateiname stimmt möglicherweise nicht genau genug mit der Episode überein, um gepaart zu werden.

## Kurzüberblick

- Textuntertitel können neu gestaltet werden; Bilduntertitel können nicht.
- Timing-Offsets werden gespeichert und überstehen einen Neustart.
- Eine passende Datei neben einer lokalen Episode wird von selbst geladen.
- Die Auswahl der Untertitel wird pro Serie gespeichert.

## Vertrag / Beispiel

```text
# Where a subtitle can come from
1. a track bundled inside the stream
2. a file sitting next to the episode on disk
3. a track the source downloads for you
4. a file you pick by hand
```
