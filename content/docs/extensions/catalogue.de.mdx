## Installiert und verfügbar

Installierte Erweiterungen funktionieren sofort. Die verfügbaren stammen aus einem Repository, das Sie hinzugefügt haben: Aktualisieren Sie die Liste und installieren Sie dann die gewünschten mit einem einzigen Tastendruck.

## Aktualisieren einer Erweiterung

Wenn eine neuere Version vorhanden ist, wird sie unter „Updates“ angezeigt. Durch die Installation wird die alte Kopie ersetzt und ihre Einstellungen bleiben erhalten, sodass eine Reparatur für Sie nichts kostet.

## Entfernen einer Erweiterung

Deinstallieren Sie es auf demselben Bildschirm. Ihre Bibliothekseinträge bleiben erhalten und werden einfach als nicht verfügbar angezeigt, bis eine andere Quelle oder eine Neuinstallation sie bereitstellen kann.

## Halten Sie die Liste lesbar

Erweiterungen sind nach Sprache gruppiert. Filtern Sie die Sprachen heraus, die Sie nicht lesen, sodass in der Liste nur Quellen angezeigt werden, die für Sie tatsächlich nützlich sind.

## Wenn nichts installiert wird

Eine fehlgeschlagene Installation liegt fast immer daran, dass Android unbekannte Apps blockiert, nicht an der Erweiterung. Erlauben Sie Installationen über Ihren Dateimanager oder Browser und versuchen Sie es dann erneut.

## Halten Sie den Katalog aktuell

Aktualisieren Sie Ihre Repositorys von Zeit zu Zeit. Neue Erweiterungen erscheinen und defekte Erweiterungen werden repariert, aber es kommt nichts an, bis Sie danach fragen.

## Wenn eine Erweiterung verschwindet

Eine installierte Erweiterung kann verschwinden, wenn Android sie entfernt hat oder wenn sie durch den Sprachfilter oder den Schalter für Inhalte für Erwachsene ausgeblendet wird. Überprüfen Sie zuerst die Filter und installieren Sie sie dann erneut aus dem Repository, wenn sie wirklich verschwunden sind.

## Kurzüberblick

- Bei Updates bleiben die Einstellungen erhalten, die Sie für eine Quelle festgelegt haben.
- Durch die Deinstallation einer Erweiterung bleiben Ihre Bibliothekseinträge erhalten.
- Erweiterungen werden nach Sprache und nicht nach Repository gruppiert.
- Durch das Aktualisieren eines Repositorys werden Ihnen neue und aktualisierte Erweiterungen angezeigt.
- Eine fehlende Erweiterung wird normalerweise durch einen Filter ausgeblendet und nicht deinstalliert.

## Vertrag / Beispiel

```text
Extensions
├── Installed    ready to browse right now
├── Available    installable from a repository you added
└── Updates      a newer version is waiting

Grouped by language, filtered by what you can read.
```
