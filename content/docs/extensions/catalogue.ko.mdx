## 설치되어 사용 가능

설치된 확장 프로그램은 즉시 작동합니다. 사용 가능한 항목은 추가한 저장소에서 가져옵니다. 목록을 새로 고친 다음 탭 한 번으로 원하는 항목을 설치하세요.

## 확장 업데이트

최신 버전이 있으면 업데이트 아래에 나타납니다. 이를 설치하면 기존 복사본이 대체되고 기본 설정이 유지되므로 수정 비용이 전혀 들지 않습니다.

## 확장 프로그램 제거

같은 화면에서 제거하세요. 라이브러리 항목은 그대로 유지되며 다른 소스나 재설치를 통해 해당 항목을 제공할 수 있을 때까지 사용할 수 없는 것으로 표시됩니다.

## 목록을 읽기 쉽게 유지하기

확장 프로그램은 언어별로 그룹화됩니다. 읽지 않는 언어를 필터링하여 목록에 실제로 유용한 소스만 표시하세요.

## 아무것도 설치되지 않을 때

설치 실패는 거의 항상 Android가 확장 프로그램이 아닌 알 수 없는 앱을 차단하는 것입니다. 파일 관리자나 브라우저에서 설치를 허용한 후 다시 시도하세요.

## 카탈로그를 최신 상태로 유지

자주 저장소를 새로 고치십시오. 새로운 확장 기능이 나타나고 손상된 확장 기능이 수정되지만 사용자가 요청할 때까지는 아무 것도 도착하지 않습니다.

## 확장자가 사라지는 경우

설치된 확장 프로그램은 Android에서 이를 제거하거나 언어 필터 또는 성인용 콘텐츠 토글에 의해 숨겨진 경우 사라질 수 있습니다. 먼저 필터를 확인한 다음 실제로 사라진 경우 저장소에서 다시 설치하세요.

## 요약

- 업데이트하면 소스에 설정한 설정이 유지됩니다.
- 확장 프로그램을 제거하면 라이브러리 항목이 유지됩니다.
- 확장은 저장소가 아닌 언어별로 그룹화됩니다.
- 저장소를 새로 고치는 것은 새로운 확장과 업데이트된 확장을 보는 방법입니다.
- 누락된 확장 프로그램은 일반적으로 제거되지 않고 필터에 의해 숨겨집니다.
