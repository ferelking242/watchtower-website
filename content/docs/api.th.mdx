## มันคืออะไร

เว็บเซิร์ฟเวอร์ขนาดเล็กที่สร้างไว้ในแอป มันใช้ส่วนขยายเดียวกันและไลบรารีเดียวกันกับอินเทอร์เฟซ ดังนั้นทุกสิ่งที่ส่งคืนจะตรงกับสิ่งที่คุณเห็นบนหน้าจอ

## กำลังเปิดเครื่อง

จะปิดจนกว่าคุณจะเปิดใช้งานโดยเจตนา เปิดสวิตช์ในการตั้งค่าขั้นสูงและจดบันทึกพอร์ต จากนั้นชี้เครื่องมือของคุณไปยังที่อยู่นั้น

## สิ่งที่คุณถามได้

แหล่งที่มาที่คุณติดตั้ง รายการไลบรารีของคุณ การค้นหากับแหล่งที่มาใดๆ และสตรีมวิดีโอที่แก้ไขแล้ว นั่นก็เพียงพอแล้วสำหรับการขับเคลื่อนมีเดียเซ็นเตอร์หรือเครื่องเล่นภายนอก

## ทำไมคุณอาจต้องการมัน

การทำงานอัตโนมัติ ส่วนหน้าอื่น หรือการอนุญาตให้อุปกรณ์อื่นในเครือข่ายของคุณใช้แหล่งที่มาที่โทรศัพท์ของคุณได้ตั้งค่าไว้แล้ว

## เก็บไว้ในเครือข่ายของคุณเอง

เซิร์ฟเวอร์ไม่มีรหัสผ่านและมีไว้สำหรับเครือข่ายท้องถิ่นที่เชื่อถือได้ อย่าเปิดเผยข้อมูลดังกล่าวบนอินเทอร์เน็ต ซึ่งใครๆ ก็สามารถอ่านห้องสมุดของคุณได้

## มันเกี่ยวข้องกับบรรทัดคำสั่งอย่างไร

บรรทัดคำสั่ง Linux เปิดเผยเซิร์ฟเวอร์เดียวกัน ดังนั้นสคริปต์ที่เขียนต่อต้านแอปจะทำงานกับเครื่องที่ไม่มีส่วนหัวโดยไม่มีการเปลี่ยนแปลง

## สรุปย่อ

- เซิร์ฟเวอร์ปิดอยู่จนกว่าคุณจะเปิดใช้งานในการตั้งค่า
- มันจะฟังบนพอร์ต 4567 โดยค่าเริ่มต้น
- มันใช้แหล่งที่มาและไลบรารีเดียวกันกับอินเทอร์เฟซ
- มีไว้สำหรับเครือข่ายท้องถิ่นที่เชื่อถือได้ ไม่ใช่อินเทอร์เน็ต

## สัญญา / ตัวอย่าง

```text
# Turn it on first, in settings
Settings → Advanced → Enable the server
# It then answers on port 4567
http://localhost:4567

GET  /sources     the sources you have installed
GET  /library     the entries in your library
POST /search      search a source
GET  /stream      resolve a video stream
```
