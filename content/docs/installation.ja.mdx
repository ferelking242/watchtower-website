## アンドロイド

メインターゲットであり、すべての機能を最初に取得する唯一のビルドです。今後の作品をテストしたい場合は、リリース APK をダウンロードするか、プレビュー APK をダウンロードしてください。 Watchtower はストアを通じて配布されていないため、Android が要求したときに不明なソースからのインストールを有効にします。

## デスクトップ

より大きな画面で視聴できるように、Windows、Linux、macOS のビルドが存在します。リリース アーティファクトは最初に Android と Linux CLI 用に公開されるため、Flutter を使用してソースからビルドします。

## Linuxコマンドライン

ウィンドウのない単一のバイナリ。同じ拡張エンジンを実行するため、サーバー上または SSH 経由でフェッチ、検索、ダウンロードできます。インストーラー スクリプトは、インストーラー スクリプトとそのランタイム ファイルを、選択したプレフィックスにコピーします。

## 安定版またはプレビュー

プレビュー ビルドは最新のコードを追跡し、より頻繁に中断します。自動バックアップを実行する場合は常にオンにし、何か問題が発生した場合はリリース ビルドを再インストールすることを想定してください。

## ソースから構築する

Flutter 3.38 以降、Dart 3.10 以降、および Rust ツールチェーンが必要です。 Go 1.21 以降は、Torrent サーバーを自分で再構築する場合にのみ必要です。

## 常に最新の状態に保ってください

新しいバージョンが存在すると Watchtower が通知し、最初と同じ方法でインストールします。ライブラリと設定はそのまま引き継がれます。

## インストールに失敗した場合

一般的なインストーラ メッセージについては、エラー ページでそれぞれ説明されています。署名の不一致は、異なる署名のコピーがすでにインストールされているため、最初に削除する必要があることを意味し、破損したダウンロードは再度取得する必要があり、プロセッサ アーキテクチャの不一致は、間違ったビルドがダウンロードされたことを意味します。

## 早見表

- Android は、リリース ビルドが公開されている唯一のプラットフォームです。
- ヘッドレス バイナリは Linux x86_64 用に構築されています。
- ソースからビルドするには Rust が必要です。 Go はオプションです。
- プレビュー インストールと安定版インストールは同じデータを共有するため、切り替えてもライブラリは保持されます。
- 競合するインストールを削除してから、別の署名のビルドに置き換えてください。

## 契約 / 例

```bash
# Android: install the APK
adb install watchtower-release.apk
# Or open the .apk file on the device and allow unknown sources

# Desktop: build from source
flutter pub get
flutter build windows    # or linux, or macos

# Linux server, no screen needed
7z x watchtower-linux-x64-headless.7z -o./watchtower-linux
sudo ./watchtower-linux/install-linux-headless.sh ./watchtower-linux
```
