## 그것은 무엇입니까

앱에 내장된 작은 웹 서버. 인터페이스와 동일한 확장 및 라이브러리를 사용하므로 반환되는 모든 항목은 화면에 표시되는 것과 일치합니다.

## 켜는 중

의도적으로 활성화할 때까지는 꺼져 있습니다. 고급 설정에서 스위치를 켜고 포트를 기록한 다음 도구로 해당 주소를 가리킵니다.

## 물어볼 수 있는 것

설치된 소스, 라이브러리 항목, 모든 소스에 대한 검색 및 확인된 비디오 스트림. 이는 미디어 센터나 외부 플레이어를 구동하기에 충분합니다.

## 당신이 그것을 원하는 이유

자동화, 다른 프런트 엔드 또는 네트워크의 다른 장치가 전화기에 이미 설정된 소스를 사용하도록 허용합니다.

## 자신의 네트워크에 보관하세요

서버에는 비밀번호가 없으며 신뢰할 수 있는 로컬 네트워크용입니다. 누구나 귀하의 라이브러리를 읽을 수 있는 인터넷에 이를 노출하지 마십시오.

## 명령줄과의 관계

Linux 명령줄은 동일한 서버를 노출하므로 앱에 대해 작성된 스크립트는 변경 없이 헤드리스 컴퓨터에 대해 작동합니다.

## 요약

- 설정에서 활성화할 때까지 서버는 꺼져 있습니다.
- 기본적으로 포트 4567에서 수신 대기합니다.
- 인터페이스와 동일한 소스와 라이브러리를 사용합니다.
- 이는 인터넷이 아닌 신뢰할 수 있는 로컬 네트워크를 위한 것입니다.

## 계약 / 예제

```text
# Turn it on first, in settings
Settings → Advanced → Enable the server
# It then answers on port 4567
http://localhost:4567

GET  /sources     the sources you have installed
GET  /library     the entries in your library
POST /search      search a source
GET  /stream      resolve a video stream
```
