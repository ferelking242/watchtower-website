## 什么是扩展

它是 JavaScript，而不是你编译的插件。它知道如何向一个网站询问其列表、搜索结果、章节和视频流，并以 Watchtower 理解的形式进行回答。

## 他们如何联系您

扩展被分组到存储库中。您添加存储库一次，它所包含的每个扩展都可以从扩展屏幕安装。

## 内容类型

扩展声明其服务内容：漫画、动画、小说、音乐或游戏。该声明决定当您点击结果时打开哪个阅读器或播放器。

## 更新和删除

扩展程序就地更新并保留其设置。卸载一个仅删除扩展；您的图书馆条目会保留下来，只需等待来源再次为它们提供服务即可。

## 为什么你应该关心是谁制造的

扩展程序在 Watchtower 内部运行，但可以访问网络并读取您提供的内容。从您信任的存储库安装，并对任何不熟悉的内容保持谨慎。

## 当扩展停止工作时

网站发生变化，来源也随之中断。这通常是一个损坏的扩展，而不是一个损坏的应用程序，并且修复会作为更新到达。

## 当安装或更新失败时

安装失败几乎总是 Android 阻止未知应用程序，更新失败是下载中途停止。允许从文件管理器或浏览器安装，然后重试，如果文件被截断，则从头开始重新安装。

## 速查表

- 扩展是 JavaScript，在应用程序内的沙箱中运行。
- 一个扩展程序覆盖一个网站。
- 安装和更新永远不会影响您的库。
- 突然失效的来源通常是网站更改。
- 安装失败的通常是 Android，而不是扩展。

## 契约 / 示例

```text
One extension  →  one website

Installed    ready to browse
Available    in a repository you added, not installed yet
Updates      a newer version exists

A repository  →  a list of extensions, hosted as one JSON file
```
