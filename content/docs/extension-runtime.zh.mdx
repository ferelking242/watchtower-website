## 什么运行你的扩展

Watchtower 使用应用程序中嵌入的小型 JavaScript 引擎。每个平台上的引擎都是相同的，这就是源在手机和服务器上表现相同的原因。

## 允许扩展执行什么操作

它可以发出网络请求，解析收到的页面并保留一些自己的设置。这就是整个工具箱。

## 它远离什么

您的文件、库、帐户和应用程序自己的屏幕。扩展程序生成的所有内容都会作为纯数据传回给应用程序进行渲染。

## 为什么慢源会拖曳

响应缓慢的源会使其自己的屏幕变慢，因为应用程序正在等待它。其他来源不受影响，因此缓慢是一个不良来源的标志，而不是重型应用程序。

## 这对信任意味着什么

沙箱限制了扩展程序可以破坏的内容，但它不判断意图。它仍然可以看到您输入的任何内容以及它获取的任何内容。从您信任的人那里安装。

## 到处都是同一个引擎

由于应用程序和 Linux 命令行共享此运行时，因此在手机上运行的扩展程序也可以在服务器上运行，无需任何更改。

## 速查表

- 扩展程序获得网络访问和页面解析，仅此而已。
- 他们无法直接读取您的文件或库。
- 一个慢速源只会减慢其自身的屏幕速度。
- 相同的沙箱可以在移动设备、桌面设备和命令行上运行。

## 契约 / 示例

```text
An extension can    reach the network, parse pages, read its own settings
An extension cannot read your files, touch your library, or draw the interface

The same sandbox runs on Android, on desktop and on the Linux command line.
```
