## ส่วนขยายของคุณทำงานอย่างไร

Watchtower ใช้เครื่องมือ JavaScript ขนาดเล็กที่ฝังอยู่ในแอป มันเป็นกลไกเดียวกันในทุกแพลตฟอร์ม ซึ่งเป็นเหตุผลว่าทำไมแหล่งข้อมูลจึงมีพฤติกรรมเหมือนกันบนโทรศัพท์และบนเซิร์ฟเวอร์

## ส่วนขยายใดที่ได้รับอนุญาตให้ทำ

สามารถส่งคำขอทางเว็บ แยกวิเคราะห์เพจที่ได้รับ และเก็บการตั้งค่าบางอย่างของตัวเองไว้ นั่นคือกล่องเครื่องมือทั้งหมด

## สิ่งที่เก็บไว้ให้ห่างจาก

ไฟล์ของคุณ ไลบรารีของคุณ บัญชีของคุณ และหน้าจอของแอปเอง ทุกอย่างที่ส่วนขยายสร้างขึ้นจะถูกส่งกลับเป็นข้อมูลธรรมดาเพื่อให้แอปแสดงผล

## เหตุใดแหล่งที่มาที่ช้าจึงลาก

แหล่งที่มาที่ตอบสนองช้าจะทำให้หน้าจอของตัวเองช้าลง เนื่องจากแอปรออยู่ แหล่งที่มาอื่นๆ จะไม่ได้รับผลกระทบ ดังนั้นความล่าช้าจึงเป็นสัญญาณของแหล่งที่มาที่ไม่ดีแหล่งเดียว ไม่ใช่แอปที่มีปริมาณมาก

## สิ่งนี้หมายถึงอะไรสำหรับความไว้วางใจ

แซนด์บ็อกซ์จำกัดสิ่งที่ส่วนขยายสามารถเสียหายได้ แต่ไม่ได้ตัดสินเจตนา มันยังคงเห็นทุกสิ่งที่คุณพิมพ์ลงไปและทุกสิ่งที่ดึงข้อมูลมา ติดตั้งจากคนที่คุณไว้วางใจ

## เครื่องยนต์เดียวกันทุกที่

เนื่องจากแอปและบรรทัดคำสั่ง Linux แชร์รันไทม์นี้ ส่วนขยายที่ทำงานบนโทรศัพท์ของคุณจึงทำงานบนเซิร์ฟเวอร์ได้เช่นกัน โดยไม่มีการเปลี่ยนแปลง

## สรุปย่อ

- ส่วนขยายได้รับการเข้าถึงเครือข่ายและการแยกวิเคราะห์หน้า ไม่มีอะไรอื่น
- พวกเขาไม่สามารถอ่านไฟล์หรือไลบรารีของคุณได้โดยตรง
- แหล่งที่มาที่ช้าแหล่งเดียวจะทำให้หน้าจอของตัวเองช้าลงเท่านั้น
- แซนด์บ็อกซ์เดียวกันทำงานบนมือถือ เดสก์ท็อป และบรรทัดคำสั่ง
