## Cara untuk membantu

Laporkan bug dengan pesan yang sama persis dengan yang Anda lihat, perbaiki sumbernya, tulis ekstensi untuk situs yang belum diliput oleh siapa pun, atau terjemahkan situs ini ke bahasa lain.

## Bekerja pada aplikasi

Kloning repositori, instal toolchain Flutter dan Rust, dan jalankan penganalisis sebelum Anda membuka permintaan pull. Go hanya diperlukan jika Anda mengganti server torrent.

## Mengerjakan dokumentasi

Situs ini adalah gudangnya sendiri. Menambah bahasa berarti menambah satu file terjemahan; tata letak dan navigasi sudah menangani sisanya.

## Menerjemahkan

Aplikasi dan situs ini menyediakan banyak bahasa, dan yang baru bersifat tambahan. Anda tidak perlu menyentuh desain untuk menambahkan bahasa Anda sendiri.

## Melaporkan bug yang bagus

Sertakan versi aplikasi Anda, sumber yang Anda gunakan, teks kesalahan sebenarnya, dan apakah sumber lain masih berfungsi. Itu biasanya cukup untuk menemukan kesalahannya.

## Sebelum perubahan besar

Buka terbitan atau tanyakan di Discord terlebih dahulu. Ini menyelamatkan Anda dari membangun sesuatu yang tidak sesuai dengan arah proyek.

## Ringkasan

- Dokumentasi adalah repositori terpisah dari aplikasi.
- Menambah bahasa berarti menambah satu file, bukan mengubah layout.
- Melaporkan teks kesalahan yang tepat akan menghemat waktu paling banyak.
- Karat diperlukan agar aplikasi berfungsi; Gunakan hanya untuk server torrent.

```bash
# Work on the app
git clone https://github.com/ferelking242/watchtower
cd watchtower && flutter pub get

git clone https://github.com/ferelking242/watchtower-website
```
