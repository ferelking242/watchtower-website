## Kategorien erstellen

Benennen Sie sie so, wie es für Sie sinnvoll ist, und ordnen Sie sie nach Ihren Wünschen an. Die meisten Menschen haben am Ende eine Handvoll davon, je nachdem, wie oft sie etwas verfolgen.

## Serien einbauen

Drücken Sie lange auf eine Serie, wählen Sie die Kategorieoption und kreuzen Sie alles an, was zutrifft. Eine Serie kann auf mehreren Regalen gleichzeitig stehen.

## Verwenden Sie sie für Updates

Richten Sie globale Updates und automatische Downloads auf bestimmte Kategorien aus. Nur die Serien, die Sie aktiv verfolgen, generieren dann Traffic.

## Eine Serie herausnehmen

Heben Sie die Auswahl einer Kategorie an derselben Stelle auf, an der Sie sie hinzugefügt haben. Die Serie bleibt in Ihrer Bibliothek, sie verlässt einfach das Regal.

## Benennen, das bleibt

Benennen Sie Kategorien nach Ihren Gewohnheiten und nicht nach Quellen. Dann führt die Migration einer Reihe zwischen Quellen nie zu einer Neuordnung Ihrer Bibliothek.

## Halten Sie es einfach

Kategorien funktionieren am besten, wenn es nur wenige davon gibt. Wenn Sie sich nicht erinnern können, wofür eine Kategorie gedacht ist, schadet sie wahrscheinlich mehr, als dass sie nützt.

## Kurzüberblick

- Eine Serie kann mehreren Kategorien gleichzeitig angehören.
- Das globale Update kann auf eine einzelne Kategorie verwiesen werden.
- Automatische Downloads können auf ausgewählte Kategorien beschränkt werden.
- Die Benennung von Kategorien nach Quellen ist in die Jahre gekommen.

## Vertrag / Beispiel

```text
Watching       updated daily
Plan to watch  never updated in the background
On hold        left alone
Completed      skipped automatically
```
