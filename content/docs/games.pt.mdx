## O que é uma fonte de jogo

Uma extensão de jogo lista títulos da mesma forma que uma extensão de mangá lista séries e abre as mesmas telas de navegação e pesquisa.

## Plataformas

Os jogos são agrupados por plataforma, o que mantém um catálogo navegável quando uma fonte abrange vários sistemas.

## Navegando e pesquisando

Pesquise fãs em fontes de jogos habilitadas exatamente como faz com outros tipos de mídia, para que uma consulta cubra todos eles.

## Instalando extensões de jogo

Eles são instalados a partir dos mesmos repositórios de todo o resto e aparecem nos jogos, uma vez instalados.

## Quando nada está listado

Uma tela de jogos vazia significa que nenhuma extensão de jogo está instalada. Adicione um repositório que forneça um e atualize.

## Mantendo-o separado

As entradas de jogos não combinam com sua leitura e visualização, portanto, um grande catálogo de jogos nunca sobrecarrega sua biblioteca.

## Resumo

- As fontes do jogo são instaladas a partir dos mesmos repositórios que todo o resto.
- Os jogos são agrupados por plataforma.
- A pesquisa cobre todas as fontes de jogos habilitadas de uma só vez.
- As entradas do jogo permanecem separadas da sua biblioteca.

## Contrato / exemplo

```text
Games
├── Extensions   game sources you have added
├── Platforms    grouped by platform
└── Browse       the same search as other media
```
