## 什么是游戏源

游戏扩展程序列出标题的方式与漫画扩展程序列出系列的方式相同，并打开相同的浏览和搜索屏幕。

## 平台

游戏按平台分组，这样当源涵盖多个系统时，目录仍可导航。

## 浏览和搜索

与其他媒体类型一样，在启用的游戏源中进行搜索，因此一个查询涵盖了所有这些源。

## 安装游戏扩展

它们与其他所有内容都从相同的存储库安装，并在安装后出现在游戏下。

## 当没有列出任何内容时

空的游戏屏幕意味着没有安装游戏扩展。添加提供一个的存储库，然后刷新。

## 保持独立

游戏条目不会与您的阅读和观看混在一起，因此大型游戏目录不会让您的图书馆变得混乱。

## 速查表

- 游戏源与其他所有内容都从相同的存储库安装。
- 游戏按平台分组。
- 搜索一次涵盖所有启用的游戏源。
- 游戏条目与您的库分开。

## 契约 / 示例

```text
Games
├── Extensions   game sources you have added
├── Platforms    grouped by platform
└── Browse       the same search as other media
```
