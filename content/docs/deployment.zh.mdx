## 你得到什么

包含命令行及其所需的运行时文件的单个文件夹。安装程序脚本将其复制到您选择的前缀中并将其设置为运行。

## 安装它

使用解压的文件夹和所需的前缀运行安装程序。在主目录下使用前缀可以避免之后的所有操作都需要 root 权限。

## 将其作为服务运行

由于它可以通过 HTTP 提供服务，因此您可以使其在后台运行，并让网络上的其他设备使用它已配置的源。

## 它有什么好处

媒体中心、预定的下载程序或保存源代码的一台机器，这样其他机器就不必这样做。它是相同的引擎，因此源的行为相同。

## 保持最新状态

通过解压较新的版本并再次运行安装程序来更新它。您的配置位于前缀中，不会被升级覆盖。

## 如果某些东西无法运行

doctor 命令正是为此而存在的。首先运行它，它会告诉您问题是运行时、网络还是源。

## 速查表

- 无头构建是一个独立的文件夹和一个安装程序。
- 安装在您的主目录下可以避免需要 root。
- 它可以通过 HTTP 向网络上的其他设备提供服务。
- doctor 命令可以诊断大多数启动失败。

## 契约 / 示例

```text
# Unpack and install, choosing your own prefix
7z x watchtower-linux-x64-headless.7z -o./watchtower-linux
./watchtower-linux/install-linux-headless.sh ./watchtower-linux \
  --prefix "$HOME/.local/share/watchtower"

# Then run it as a service and point clients at the port it serves
```
