## Avvio di un download

Aggiungi capitoli o episodi di una serie e si uniranno alla coda di download. Dalla coda puoi riordinare ciò che verrà dopo o cancellare qualcosa che non desideri più.

## Perché uno alla volta

Watchtower scarica una serie alla volta da qualsiasi singola fonte. Inviare molte richieste a un sito è esattamente ciò che attiva la protezione anti-bot che blocca le fonti.

## Modalità solo download

Attivalo per nascondere tutto ciò che non hai salvato. L'app mostra quindi solo ciò che è presente sul tuo dispositivo, il che è utile durante un viaggio o una connessione a consumo.

## Dove sono archiviati i file

I download arrivano in una cartella che prende il nome dalla fonte, quindi dalla serie. Rinominare una delle cartelle interrompe il rilevamento, quindi lasciale stare.

## Quando i download scompaiono

Se il contenuto salvato smette di essere visualizzato, probabilmente la cartella di archiviazione è stata spostata o è diventata illeggibile. Controlla la posizione di archiviazione e ricostruisci l'indice dei download.

## Ciò che un backup non copre

I file di backup contengono la tua libreria e le tue impostazioni, mai i tuoi contenuti multimediali scaricati. Questi devono essere spostati separatamente.

## Quando un download fallisce parzialmente

Un download interrotto è solitamente una connessione interrotta o una fonte che ha smesso di rispondere. Riprovare dalla coda, poiché vengono conservati file parziali, e passare al Wi-Fi se la causa è la rete. Le risposte persistenti 403 o 429 significano che la fonte ti sta rifiutando, non che il file è sparito.

## Riepilogo

- Viene scaricata solo una serie per fonte alla volta, apposta.
- Il supporto scaricato non è incluso in un backup.
- La memoria interna è più veloce e affidabile di una scheda SD.
- La ridenominazione della cartella dei download interrompe il rilevamento.
- Un download interrotto conserva i file parziali, quindi riprovare lo riprende.

## Contratto / esempio

```text
downloads/
└── Source name (LANG)/
    └── Series title/
        ├── Chapter 01.cbz
        └── Episode 01.mp4

One source downloads at a time; different sources run together.
```
