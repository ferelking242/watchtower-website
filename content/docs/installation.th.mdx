## หุ่นยนต์

เป้าหมายหลักและเป็นรุ่นเดียวที่ได้รับทุกคุณสมบัติก่อน ดาวน์โหลด APK ที่เผยแพร่หรือ APK ตัวอย่างหากคุณต้องการทดสอบงานที่จะเกิดขึ้น เปิดใช้งานการติดตั้งจากแหล่งที่ไม่รู้จักเมื่อ Android ถาม เนื่องจาก Watchtower ไม่ได้เผยแพร่ผ่านร้านค้า

## เดสก์ท็อป

มีบิลด์ Windows, Linux และ macOS สำหรับการรับชมบนหน้าจอที่ใหญ่ขึ้น สร้างจากแหล่งที่มาด้วย Flutter เนื่องจากสิ่งประดิษฐ์ที่เผยแพร่จะถูกเผยแพร่สำหรับ Android และ Linux CLI ก่อน

## บรรทัดคำสั่งลินุกซ์

ไบนารีเดียวที่ไม่มีหน้าต่าง มันรันเอ็นจิ้นส่วนขยายเดียวกัน ดังนั้นจึงสามารถดึงข้อมูล ค้นหา และดาวน์โหลดบนเซิร์ฟเวอร์หรือบน SSH สคริปต์ตัวติดตั้งจะคัดลอกสคริปต์และไฟล์รันไทม์ลงในคำนำหน้าที่คุณเลือก

## เสถียรหรือแสดงตัวอย่าง

ดูตัวอย่างบิลด์ติดตามโค้ดใหม่ล่าสุดและพังบ่อยขึ้น เปิดการสำรองข้อมูลอัตโนมัติไว้หากคุณใช้งาน และคาดว่าจะติดตั้งเวอร์ชันรีลีสใหม่หากมีสิ่งผิดปกติเกิดขึ้น

## การสร้างจากแหล่งที่มา

คุณต้องมี Flutter 3.38 หรือใหม่กว่า, Dart 3.10 หรือใหม่กว่า และ Toolchain Rust จำเป็นต้องใช้ Go 1.21 หรือใหม่กว่าเฉพาะในกรณีที่คุณต้องการสร้างเซิร์ฟเวอร์ torrent ใหม่ด้วยตัวเอง

## ให้มันปรับปรุง

Watchtower จะแจ้งให้คุณทราบเมื่อมีเวอร์ชันใหม่ และคุณติดตั้งในลักษณะเดียวกับครั้งแรก ห้องสมุดและการตั้งค่าของคุณยังคงไม่มีใครแตะต้อง

## หากการติดตั้งล้มเหลว

ข้อความของโปรแกรมติดตั้งทั่วไปจะมีการอธิบายไว้ในหน้าข้อผิดพลาด ลายเซ็นไม่ตรงกันหมายถึงมีการติดตั้งสำเนาที่เซ็นชื่อเป็นอย่างอื่นแล้ว และต้องลบออกก่อน การดาวน์โหลดที่เสียหายจำเป็นต้องเรียกข้อมูลอีกครั้ง และสถาปัตยกรรมโปรเซสเซอร์ที่ไม่ตรงกันหมายความว่ามีการดาวน์โหลดบิลด์ที่ไม่ถูกต้อง

## สรุปย่อ

- Android เป็นแพลตฟอร์มเดียวที่มีรุ่นเผยแพร่ที่เผยแพร่
- ไบนารี่ที่ไม่มีหัวถูกสร้างขึ้นสำหรับ Linux x86_64
- จำเป็นต้องมีสนิมเพื่อสร้างจากแหล่งที่มา ไปเป็นทางเลือก
- การติดตั้งตัวอย่างและการติดตั้งที่เสถียรจะใช้ข้อมูลเดียวกัน ดังนั้นการสลับจะเก็บไลบรารีของคุณไว้
- ลบการติดตั้งที่ขัดแย้งกันก่อนที่จะแทนที่ด้วยบิลด์ที่มีการเซ็นชื่ออื่น

## สัญญา / ตัวอย่าง

```bash
# Android: install the APK
adb install watchtower-release.apk
# Or open the .apk file on the device and allow unknown sources

# Desktop: build from source
flutter pub get
flutter build windows    # or linux, or macos

# Linux server, no screen needed
7z x watchtower-linux-x64-headless.7z -o./watchtower-linux
sudo ./watchtower-linux/install-linux-headless.sh ./watchtower-linux
```
