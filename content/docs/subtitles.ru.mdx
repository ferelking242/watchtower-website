## Выбор трека

Если эпизод содержит несколько дорожек субтитров, они перечислены в листе субтитров. Ваш выбор запоминается для этой серии, поэтому вы выбираете только один раз.

## Исправление времени

Дорожку, которая идет впереди или позади аудио, можно небольшими шагами сдвигать, пока она не выровняется. Смещение запоминается, поэтому исправление сохраняется при перезапуске приложения.

## Стиль

К текстовым субтитрам применяются шрифт, размер, цвет, контур и фон. Эти настройки не затрагивают видео, и с ними можно смело экспериментировать в середине эпизода.

## Ваши собственные файлы

Поместите файл субтитров рядом с локальным эпизодом с соответствующим названием, и проигрыватель загрузит его автоматически, без необходимости изменения настроек.

## Субтитры встроены в изображение

Некоторые субтитры представляют собой изображения, а не текст. Их нельзя изменить, можно только изменить положение или размер, поскольку стиль является частью самого изображения.

## Когда субтитры не появляются

Сначала проверьте лист субтитров: источник может их не предлагать, или имя файла может не соответствовать эпизоду настолько, чтобы его можно было соединить.

## Памятка

- Текстовые субтитры можно изменить; субтитры изображений не могут.
- Смещения времени сохраняются и сохраняются при перезапуске.
- Соответствующий файл рядом с локальным эпизодом загружается сам по себе.
- Выбор субтитров запоминается для каждой серии.

## Контракт / пример

```text
# Where a subtitle can come from
1. a track bundled inside the stream
2. a file sitting next to the episode on disk
3. a track the source downloads for you
4. a file you pick by hand
```
