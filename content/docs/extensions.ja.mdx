## 拡張機能とは

これは JavaScript であり、コンパイルするプラグインではありません。これは、ある Web サイトにそのリスト、検索結果、チャプター、ビデオ ストリームを問い合わせる方法を知っており、Watchtower が理解できる形で答えます。

## どのようにしてあなたに届くのか

拡張機能はリポジトリにグループ化されます。リポジトリを一度追加すると、リポジトリに保持されているすべての拡張機能が拡張機能画面からインストールできるようになります。

## コンテンツの種類

拡張機能は、マンガ、アニメ、小説、音楽、ゲームなど、何を提供するかを宣言します。この宣言により、結果をタップしたときにどのリーダーまたはプレーヤーが開くかが決まります。

## 更新と削除

拡張機能は適切に更新され、設定が維持されます。拡張機能をアンインストールすると、拡張機能のみが削除されます。ライブラリのエントリは存続し、ソースがそれらを再び提供するのを待つだけです。

## なぜ誰が作ったかを気にする必要があるのか

拡張機能は Watchtower 内で実行されますが、ネットワークに到達して、ネットワークに与えられたものを読み取ることができます。信頼できるリポジトリからインストールし、不慣れなものには注意してください。

## 拡張機能が動作しなくなったとき

ウェブサイトは変化し、情報源はウェブサイトから切り離されます。これは通常、壊れたアプリではなく、壊れた拡張機能であり、修正はアップデートとして提供されます。

## インストールまたはアップデートが失敗した場合

インストールの失敗は、ほとんどの場合、Android が不明なアプリをブロックすることであり、アップデートの失敗は、ダウンロードが途中で停止することです。ファイル マネージャーまたはブラウザからのインストールを許可してから再試行し、ファイルが切り詰められている場合は最初から再インストールします。

## 早見表

- 拡張機能は JavaScript であり、アプリ内のサンドボックスで実行されます。
- 1 つの拡張機能で 1 つの Web サイトをカバーします。
- インストールと更新によってライブラリが変更されることはありません。
- 突然障害が発生する原因は通常、Web サイトの変更です。
- インストールに失敗するのは通常、拡張機能ではなく Android です。

One extension  →  one website
