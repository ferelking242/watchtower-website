## Qu'est-ce qu'une source de jeu

Une extension de jeu répertorie les titres de la même manière qu'une extension de manga répertorie les séries et ouvre les mêmes écrans de navigation et de recherche.

## Plateformes

Les jeux sont regroupés par plateforme, ce qui permet de conserver un catalogue navigable lorsqu'une source couvre plusieurs systèmes.

## Navigation et recherche

Recherchez les fans parmi les sources de jeu activées exactement comme pour les autres types de médias, donc une seule requête les couvre tous.

## Installation d'extensions de jeu

Ils s'installent à partir des mêmes référentiels que tout le reste et apparaissent sous les jeux une fois installés.

## Quand rien n'est répertorié

Un écran de jeux vide signifie qu’aucune extension de jeu n’est installée. Ajoutez un référentiel qui en fournit un, puis actualisez.

## Le garder séparé

Les entrées de jeux ne se mélangent pas avec votre lecture et votre visionnage, donc un grand catalogue de jeux n'encombre jamais votre bibliothèque.

## Mémo

- Les sources du jeu s'installent à partir des mêmes référentiels que tout le reste.
- Les jeux sont regroupés par plateforme.
- La recherche couvre toutes les sources de jeu activées à la fois.
- Les entrées de jeu restent séparées de votre bibliothèque.

## Contrat / exemple

```text
Games
├── Extensions   game sources you have added
├── Platforms    grouped by platform
└── Browse       the same search as other media
```
