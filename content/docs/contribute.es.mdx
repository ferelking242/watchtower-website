## Maneras de ayudar

Informa errores con el mensaje exacto que viste, mejora una fuente, escribe una extensión para un sitio que nadie ha cubierto o traduce este sitio a otro idioma.

## Trabajando en la aplicación

Clona el repositorio, instala las cadenas de herramientas Flutter y Rust y ejecuta el analizador antes de abrir una solicitud de extracción. Ir solo es necesario si estás cambiando el servidor de torrent.

## Trabajando en la documentacion

El sitio es su propio repositorio. Agregar un idioma significa agregar un archivo de traducción; el diseño y la navegación ya se encargan del resto.

## Traductorio

Tanto la aplicación como este sitio ofrecen muchos idiomas y uno nuevo es aditivo. Nunca tendrás que tocar el diseño para agregar tu propio idioma.

## Informar de un buen error

Incluye la versión de tu aplicación, la fuente que estabas usando, el texto exacto del error y si otras fuentes aún funcionan. Esto suele ser suficiente para localizar la avería.

## Antes de un gran cambio

Primero abra una edición o pregunte en Discord. Le ahorra construir algo que no se ajusta al rumbo del proyecto.

## Chuleta

- La documentación es un repositorio separado de la aplicación.
- Agregar un idioma significa agregar un archivo, no cambiar el diseño.
- Informar el texto de error exacto ahorra la mayor parte del tiempo.
- Se necesita óxido para que la aplicación funcione; Elija solo el servidor torrent.
