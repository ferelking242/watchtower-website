# Watchtower

Watchtower is an open, extension-driven media reader. The app owns navigation, storage, rendering, and user experience; extensions describe where content comes from and how it should be presented.

## The principle

> Extensions provide data. Watchtower provides the product.

This boundary keeps source integrations replaceable and makes interface improvements available to every extension at once.
