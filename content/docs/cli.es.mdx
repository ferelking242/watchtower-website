## para que es

Servidores, sesiones SSH y trabajos automatizados. Es el mismo motor de extensión que la aplicación con una interfaz de texto en lugar de pantallas, por lo que no necesita sesión gráfica.

## Orientarse

Comience con el comando de ayuda, luego ejecute el comando doctor para confirmar que el tiempo de ejecución puede cargarse y alcanzar todo lo que necesita antes de confiarle un trabajo.

## Trabajar con extensiones

Enumere lo que ofrece un repositorio, valídelo y pruebe una fuente con el sitio activo. La prueba se ejecuta en etapas, desde simplemente cargar la fuente hasta ejercitar su búsqueda y llamadas detalladas.

## Llamar a una fuente directamente

Puede invocar una única operación, como una búsqueda, y recuperar JSON. Eso es lo que hace que la línea de comando sea útil para crear scripts y depurar una fuente.

## Sirviendo a través de la red

Puede iniciar el mismo servidor web que expone la aplicación, que es la forma en que un cliente remoto habla con una máquina sin cabeza.

## Lo que no hace todavía

Los comandos de biblioteca, historial y cola de descargas no están disponibles sin cabeza porque la línea de comandos no abre las bases de datos locales de la aplicación. Esos todavía necesitan la aplicación.

## Chuleta

- La línea de comando reutiliza el motor de extensión de la aplicación.
- El comando doctor verifica el tiempo de ejecución antes de confiar en él.
- Una fuente se puede probar en etapas, desde la carga hasta la búsqueda.
- Los comandos de biblioteca y descarga aún requieren la aplicación.

## Contrato / ejemplo

```bash
watchtower --cli help
watchtower --cli doctor --json
watchtower --cli extensions list --repo ./my-repo
watchtower --cli extensions test --repo ./my-repo --mode smoke
watchtower --cli source 1900000002 search --query "space opera" --json
```
