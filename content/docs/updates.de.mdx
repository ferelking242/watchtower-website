## Globales Update

Läuft durch Ihre gesamte Bibliothek und meldet, was neu ist. Beschränken Sie es auf die Kategorien, denen Sie tatsächlich folgen, damit langsame Serien nicht umsonst jeden Tag überprüft werden.

## Was wird übersprungen

Serien, die Sie abgeschlossen haben, Serien, die Sie noch nicht begonnen haben, und Serien ohne erwartete Veröffentlichung werden automatisch übersprungen. Das ist es, was eine große Bibliothek davon abhält, eine Flut von Anfragen zu erzeugen.

## Benachrichtigungen

Bei neuen Kapiteln und Episoden wird eine Benachrichtigung angezeigt, die Sie auf eine Kategorie eingrenzen oder ganz ausschalten können, ohne die Aktualisierungen auszuschalten.

## Auffrischung einer Serie

Öffnen Sie das Serienmenü und aktualisieren Sie es, wenn Sie es sofort überprüfen möchten, ohne alles andere zu aktualisieren.

## Warum das wichtig ist

Eine Quelle, die zu viele Anfragen erhält, kann mit dem Anti-Bot-Schutz die gesamte App blockieren. Durch die Beschränkung der Aktualisierungen auf das, was Sie verfolgen, werden die Quellen geschützt, auf die jeder angewiesen ist.

## Wenn Updates scheinbar nicht mehr funktionieren

Durch die Optimierung des Android-Akkus kann die Hintergrundarbeit unterbrochen werden. Befreien Sie Watchtower von den Batteriebeschränkungen, wenn Updates nur eintreffen, wenn Sie die App öffnen.

## Wenn ein Update einen Fehler meldet

Ein Update, das bei einer Serie fehlschlägt, liegt normalerweise an dieser Quelle und nicht an der App. Aktualisieren Sie die Serie manuell, aktualisieren Sie die Erweiterung und denken Sie daran, dass sich die Ratenbegrenzung nach einem großen Update-Lauf mit der Zeit und nicht bei Wiederholungsversuchen von selbst auflöst.

## Kurzüberblick

- Aktualisierungen können auf die von Ihnen ausgewählten Kategorien beschränkt werden.
- Abgeschlossene Serien werden standardmäßig übersprungen.
- Starker Update-Verkehr kann dazu führen, dass die App blockiert wird.
- Die Batterieoptimierung kann Hintergrundaktualisierungen verzögern.
- Ein fehlgeschlagenes Update einer Serie deutet auf diese Quelle hin, nicht auf die App.

## Vertrag / Beispiel

```text
# Two ways to update
Global update   the whole library, on a schedule
Manual refresh  one series, whenever you want

# Where to find it
More → Updates        check everything
Series → menu → Refresh   check just this one
```
