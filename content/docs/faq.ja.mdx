## なぜアプリストアにないのですか？

Watchtower は、ストア ポリシーで許可されていない拡張機能を実行時にインストールするためです。すべてのインストールが、信頼することを選択した APK から行われるのもそのためです。

## iOS版はありますか？

基礎となるコードはクロスプラットフォームですが、iOS での配布はプラットフォームのルールによって制約されており、約束されていません。 Android は、すべてを最初に実現するプラットフォームです。

## インターネットなしでも動作しますか?

ダウンロードしたものとローカル ファイルはすべて、完全にオフラインで動作します。ソースの閲覧や検索には Web サイト自体が必要なため、必要ありません。

## デバイス間で同期できますか?

自動同期はありません。ライブラリをバックアップ ファイルとともに移動するため、ダウンロードしたメディアを個別にコピーする必要があります。

## それは合法であり、無料ですか？

Watchtower は無料のオープンソースであり、独自のコンテンツは含まれていません。拡張機能を通じて何を追加するかはユーザーの責任であるため、アプリは拡張機能を精査していないと慎重に述べています。

## インストールされているソースが表示されないのはなぜですか?

2 つのフィルターはソースを削除せずに非表示にします。拡張機能がデバイス以外の言語を提供する場合は、ソース リスト フィルターでその言語をオンにします。アダルト ソースの場合は、リストに NSFW ソースを表示するオプションを有効にします。

## 拡張機能をアンインストールするにはどうすればよいですか?

拡張機能画面からアンインストールするか、Android 設定の他のアプリと同様にアンインストールします。ライブラリ エントリはそのまま残り、別のソースが提供できるようになるまで利用不可として表示されます。

## ダウンロードしたものが表示されないのはなぜですか?

ダウンロードはフォルダーごとに検出されます。保存場所が移動した場合、SD カードが削除された場合、またはサイト上でソースまたはシリーズの名前が変更された場合、アプリはフォルダーを一致させることができません。場所を修正するか、フォルダーの名前を変更して、ダウンロード インデックスを再構築します。

## 私のフォトギャラリーに表紙やエピソードが表示されるのはなぜですか?

アプリは通常、.nomedia ファイルを使用してシステム ギャラリーからメディアを非表示にします。そうでない場合は、自分で作成してダウンロード フォルダーにドロップするか、それが漏洩した場合はローカル ソース フォルダーにドロップします。

## 読み取りや読み込みが遅いのはなぜですか?

読み込みが遅いのはサイト、接続、またはレート制限が原因であり、アプリが重いわけではありません。章内の画像が大きすぎると読み込みの遅れが発生するため、メモリを解放するか、スキャンが小さいソースを選択してください。

## 一部のエピソードが表示されないのはなぜですか?

ネットワークの問題とは別に、アプリがビデオの存在を見逃すことがあります。通常、プレーヤーを離れてエピソードを再度開くと、エピソードが登録されます。

## ライブラリの更新でエントリがスキップされるのはなぜですか?

未視聴または未読のコンテンツを含むエントリ、開始していないエントリ、完了とマークされたエントリ、およびリリースが予定されていないエントリは、意図的にスキップされます。これにより、大規模なライブラリがソースを攻撃したり、アプリがブロックされたりすることがなくなります。

## ライブラリの更新がバックグラウンドで停止するのはなぜですか?

一部の Android ビルドは積極的にバッテリーを節約し、バックグラウンド作業を一時停止します。アプリを開いたときにのみアップデートが届く場合は、Watchtower をバッテリーの最適化から除外します。

## スクリーンショットの撮影がブロックされるのはなぜですか?

タスクスイッチャーでアプリを非表示にするプライバシー設定もスクリーンショットをブロックします。画面をキャプチャしたい場合は、その設定をオフにしてください。

## 何かが壊れた、今はどうなっているの？

ほとんどの破損は修正されるため、まず拡張機能を更新してください。問題が解決しない場合は、アプリに問題があると考える前に、エラー ページで表示されている正確なメッセージを確認し、次にトラブルシューティング ページを確認してください。

## 早見表

- Watchtower はアプリ ストアを通じて配布されません。
- ダウンロードしたコンテンツとローカル ファイルは完全にオフラインで動作します。
- デバイス間の自動同期はありません。
- 非表示のソースは通常、言語フィルターまたは NSFW トグルです。
- ダウンロードはフォルダー名で照合されるため、名前を変更すると非表示になります。
- 拡張機能を更新すると、突然の破損のほとんどが修正されます。

Is it on a store?        No. Installable extensions conflict with store rules.
Is there an iOS build?   The code supports it; shipping it is not promised.
Does it work offline?    Downloads and local files do, browsing does not.
Does it sync?            No. Move your library with a backup file.
Is it free?              Yes, and the source is open under Apache 2.0.

Missing sources?   check the language filter and the NSFW toggle
Missing downloads? check the storage folder and rebuild the index
