## 选择曲目

当一集带有多个字幕轨道时，它们会列在字幕表中。该系列会记住您的选择，因此您只能选择一次。

## 修复时间安排

可以小步微调在音频之前或之后运行的轨道，直到其对齐。偏移量会被记住，因此修复在重新启动应用程序后仍然有效。

## 造型

字体、大小、颜色、轮廓和背景适用于文本字幕。这些设置不会影响视频，可以安全地在中间剧集中进行实验。

## 您自己的文件

将字幕文件放在具有匹配名称的本地剧集旁边，播放器会自动加载它，无需更改设置。

## 字幕已融入图像中

有些字幕是图片而不是文字。它们无法重新设计，只能重新定位或调整大小，因为样式是图像本身的一部分。

## 当字幕不出现时

首先检查字幕表：源可能没有提供字幕表，或者文件名可能与剧集不够紧密匹配而无法配对。

## 速查表

- 文本字幕可以重新设计；图片字幕不能。
- 时间偏移被保存并在重新启动后继续存在。
- 本地剧集旁边的匹配文件会自行加载。
- 每个系列都会记住字幕选择。

## 契约 / 示例

```text
# Where a subtitle can come from
1. a track bundled inside the stream
2. a file sitting next to the episode on disk
3. a track the source downloads for you
4. a file you pick by hand
```
