## Modi per aiutare

Segnala bug con il messaggio esatto che hai visto, migliora una fonte, scrivi un'estensione per un sito che nessuno ha trattato o traduci questo sito in un'altra lingua.

## Lavorando sull'app

Clona il repository, installa le toolchain Flutter e Rust ed esegui l'analizzatore prima di aprire una richiesta pull. Go è necessario solo se stai cambiando il server torrent.

## Lavorando sulla documentazione

Il sito è il proprio repository. Aggiungere una lingua significa aggiungere un file di traduzione; il layout e la navigazione gestiscono già il resto.

## Tradurre

L'app e questo sito forniscono entrambi molte lingue e una nuova è additiva. Non devi mai toccare il design per aggiungere la tua lingua.

## Segnalazione di un bug utile

Includi la versione dell'app, la fonte che stavi utilizzando, il testo esatto dell'errore e se altre fonti funzionano ancora. Di solito questo è sufficiente per individuare il guasto.

## Prima di un grande cambiamento

Apri un problema o chiedi prima su Discord. Ti evita di costruire qualcosa che non si adatta alla direzione del progetto.

## Riepilogo

- La documentazione è un repository separato dall'app.
- Aggiungere una lingua significa aggiungere un file, non modificare il layout.
- Segnalare il testo esatto dell'errore consente di risparmiare molto tempo.
- Rust è necessario per il funzionamento dell'app; Vai solo per il server torrent.

## Contratto / esempio

```bash
# Work on the app
git clone https://github.com/ferelking242/watchtower
cd watchtower && flutter pub get

# Work on this documentation
git clone https://github.com/ferelking242/watchtower-website
```
