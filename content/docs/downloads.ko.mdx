## 다운로드 시작

시리즈의 장이나 에피소드를 추가하면 다운로드 대기열에 추가됩니다. 대기열에서 다음에 올 항목을 재정렬하거나 더 이상 원하지 않는 항목을 취소할 수 있습니다.

## 왜 한 번에 하나씩

Watchtower는 단일 소스에서 한 번에 하나의 시리즈를 다운로드합니다. 한 사이트에서 많은 요청을 실행하는 것이 바로 소스를 차단하는 안티봇 보호를 실행하는 것입니다.

## 다운로드 전용 모드

저장하지 않은 항목을 숨기려면 이 옵션을 켜세요. 그러면 앱은 기기에 있는 내용만 표시하므로 여행이나 데이터 통신에 유용합니다.

## 파일이 저장되는 위치

다운로드는 소스 이름을 딴 폴더와 시리즈 폴더 아래에 저장됩니다. 두 폴더 중 하나의 이름을 바꾸면 감지가 중단되므로 그대로 두십시오.

## 다운로드가 사라질 때

저장된 콘텐츠 표시가 중지되면 저장소 폴더가 이동되었거나 읽을 수 없게 된 것일 수 있습니다. 저장 위치를 ​​확인하고 다운로드 색인을 다시 작성하세요.

## 백업에서 다루지 않는 것

백업 파일에는 다운로드한 미디어가 아닌 라이브러리와 설정이 포함됩니다. 그것들은 별도로 옮겨야 합니다.

## 다운로드가 도중에 실패하는 경우

중지된 다운로드는 일반적으로 연결이 끊어졌거나 소스가 응답을 중지한 것입니다. 일부 파일이 보관되어 있으므로 대기열에서 다시 시도하고, 네트워크 문제인 경우 Wi-Fi로 전환하세요. 지속적인 403 또는 429 응답은 파일이 사라졌다는 의미가 아니라 소스가 사용자를 거부한다는 의미입니다.

## 요약

- 의도적으로 한 번에 소스당 하나의 시리즈만 다운로드합니다.
- 다운로드한 미디어는 백업에 포함되지 않습니다.
- 내부 저장소는 SD 카드보다 빠르고 안정적입니다.
- 다운로드 폴더의 이름을 바꾸면 감지가 중단됩니다.
- 중지된 다운로드는 부분 파일을 유지하므로 다시 시도하면 다운로드가 다시 시작됩니다.
