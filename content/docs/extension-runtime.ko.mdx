## 확장 프로그램을 실행하는 항목

Watchtower는 앱에 내장된 작은 JavaScript 엔진을 사용합니다. 이는 모든 플랫폼에서 동일한 엔진이므로 소스가 전화와 서버에서 동일하게 작동합니다.

## 확장 프로그램이 수행할 수 있는 작업

웹 요청을 하고, 수신한 페이지를 구문 분석하고, 몇 가지 자체 설정을 유지할 수 있습니다. 이것이 전체 도구 상자입니다.

## 무엇을 멀리해야 하는가

귀하의 파일, 라이브러리, 계정 및 앱 자체 화면. 확장 프로그램이 생성하는 모든 것은 앱이 렌더링할 일반 데이터로 다시 전달됩니다.

## 느린 소스가 드래그되는 이유

느리게 응답하는 소스는 앱이 이를 기다리기 때문에 자체 화면을 느리게 만듭니다. 다른 소스는 영향을 받지 않으므로 속도가 느린 것은 무거운 앱이 아니라 하나의 잘못된 소스를 나타내는 신호입니다.

## 이것이 신뢰에 미치는 영향

샌드박스는 확장 프로그램이 중단할 수 있는 범위를 제한하지만 의도를 판단하지는 않습니다. 사용자가 입력하는 모든 내용과 가져오는 모든 내용을 계속 볼 수 있습니다. 신뢰하는 사람들로부터 설치하세요.

## 어디서나 동일한 엔진

앱과 Linux 명령줄은 이 런타임을 공유하므로 휴대폰에서 작동하는 확장 프로그램은 변경 없이 서버에서도 작동합니다.

## 요약

- 확장 프로그램은 네트워크 액세스 및 페이지 구문 분석만 수행합니다.
- 그들은 귀하의 파일이나 라이브러리를 직접 읽을 수 없습니다.
- 하나의 느린 소스는 자체 화면만 느리게 만듭니다.
- 동일한 샌드박스가 모바일, 데스크톱 및 명령줄에서 실행됩니다.
