## 403 สิ่งต้องห้าม

เว็บไซต์ตัดสินใจว่าคำขอของคุณดูเป็นแบบอัตโนมัติและกำลังปฏิเสธ ในทางปฏิบัตินี่คือการป้องกันต่อต้านบอท อัปเดตส่วนขยายก่อน จากนั้นเปิดซอร์สในเบราว์เซอร์ในตัวหนึ่งครั้งเพื่อล้างการตรวจสอบที่ไซต์ถืออยู่ หากยังคงปฏิเสธ แหล่งที่มาอาจเพิ่มความคุ้มครองหรือบล็อกที่อยู่ของคุณ

## 404 ไม่พบ

หน้าที่ส่วนขยายคาดว่าจะถูกย้ายหรือถูกลบออก นี่เป็นส่วนขยายเก่าเกือบทุกครั้ง ดังนั้นให้รีเฟรชพื้นที่เก็บข้อมูลของคุณและอัปเดต หากไม่มีการอัปเดต แสดงว่าผู้เขียนส่วนขยายยังตามเว็บไซต์ไม่ทัน

## 429 คำขอมากเกินไป

คุณถูกจำกัดอัตราสำหรับการร้องขอเร็วเกินไป การรอคือการแก้ไขที่แท้จริง และการลดความถี่ในการอัปเดตและการดาวน์โหลดคือสิ่งที่หยุดไม่ให้เกิดขึ้นอีก การลองใหม่ทันทีจะขยายบล็อกเท่านั้น

## 500, 502 และข้อผิดพลาด 5xx อื่นๆ

ตัวเว็บไซต์เองก็ล้มเหลว ไม่มีอะไรต้องแก้ไขบนอุปกรณ์ของคุณ และการดำเนินการที่ถูกต้องคือรอแล้วลองอีกครั้งในภายหลัง การตรวจสอบเว็บไซต์ในเบราว์เซอร์จะช่วยยืนยันว่าเว็บไซต์นั้นล่มสำหรับทุกคนหรือไม่

## 1006 และ 1020 รหัสไฟร์วอลล์

โดยทั่วไป 1006 หมายถึงการแบน IP ชั่วคราว และ 1020 หมายถึงกฎไฟร์วอลล์ที่เจ้าของไซต์กำหนด ซึ่งมักจะบล็อกผู้เยี่ยมชมจากนอกประเทศของตน การเปลี่ยนเครือข่ายสามารถช่วยได้ 1,006; โดยปกติแล้ว 1,020 จะไม่สามารถแก้ไขได้

## ไม่สามารถหลีกเลี่ยง Cloudflare

ไซต์ได้รับการคุ้มครองโดย Cloudflare และการตรวจสอบอัตโนมัติไม่ชัดเจน เปิดหน้าแหล่งที่มาในเบราว์เซอร์ในตัวและดำเนินการยืนยันด้วยตนเอง จากนั้นจึงกลับไปที่แอป หากหน้าโหลดซ้ำไม่รู้จบ โปรดดูหน้าการแก้ปัญหา

## ไม่สามารถแก้ไขโฮสต์ การเชื่อมต่อล้มเหลว หมดเวลา

ปัญหาเหล่านี้เป็นปัญหาเครือข่ายมากกว่าข้อผิดพลาดในแหล่งที่มา ตรวจสอบว่าอุปกรณ์มีการเข้าถึงอินเทอร์เน็ต ลองใช้เครือข่ายหรือข้อมูลมือถืออื่น และเปิดใช้งาน DNS ที่เข้ารหัสในการตั้งค่า พอร์ทัล Wi-Fi แบบ Captive เป็นสาเหตุที่พบบ่อย

## การตรวจสอบใบรับรองล้มเหลว

ไม่สามารถตรวจสอบใบรับรองความปลอดภัยของไซต์ได้ ตรวจสอบว่าวันที่และเวลาของอุปกรณ์ถูกต้อง ล้างแคชและคุกกี้ของแอป แล้วลองใช้เครือข่ายอื่น ใบรับรองที่หมดอายุบนไซต์ไม่ใช่สิ่งที่คุณสามารถแก้ไขได้

## ข้อผิดพลาดในการจัดเก็บและการ์ด SD

ข้อความเกี่ยวกับการ์ด เส้นทาง หรือโฟลเดอร์ที่ไม่พร้อมใช้งานหมายความว่าตำแหน่งการดาวน์โหลดถูกย้ายหรือไม่สามารถอ่านได้ ตรวจสอบพื้นที่ว่าง ยืนยันว่าแอปยังคงมีสิทธิ์เข้าถึงโฟลเดอร์นั้น และเปลี่ยนกลับไปเป็นที่จัดเก็บข้อมูลภายในหากการ์ดยังคงทำงานล้มเหลว

## แอปหรือส่วนขยายจะไม่ติดตั้ง

APK ที่ลงนามโดยบุคคลอื่น การดาวน์โหลดที่ถูกตัดทอน และสถาปัตยกรรมตัวประมวลผลที่ไม่ถูกต้อง ต่างก็สร้างข้อความการติดตั้งที่แตกต่างกัน ลบสำเนาที่ขัดแย้งออกแล้วดาวน์โหลดไฟล์อีกครั้ง และตรวจสอบให้แน่ใจว่า Android ได้รับอนุญาตให้ติดตั้งแอปที่ไม่รู้จัก

## เมื่อข้อผิดพลาดไม่อยู่ในรายการที่นี่

คัดลอกข้อความให้ตรงทั้งหมดแทนที่จะถอดความ ชื่อการดำเนินการและ URL ภายในมักจะชี้ตรงไปยังขั้นตอนที่ล้มเหลว และหน้าการแก้ไขปัญหาจะอธิบายให้แคบลง

## สรุปย่อ

- 403 และ 429 ทั้งคู่หมายความว่าไซต์ปฏิเสธคุณด้วยเหตุผลที่แตกต่างกัน
- 404 เป็นส่วนขยายที่ต้องอัปเดตเกือบทุกครั้ง
- ข้อผิดพลาด 5xx เป็นความผิดของเว็บไซต์ ไม่ใช่อุปกรณ์ของคุณ
- 1006 เป็นการห้ามชั่วคราว 1020 เป็นกฎไฟร์วอลล์ที่คุณไม่สามารถหลีกเลี่ยงได้
- คัดลอกข้อความให้ตรงกันทุกประการ: URL ที่อยู่ข้างในจะตั้งชื่อขั้นตอนที่ล้มเหลว
- ลายเซ็นไม่ตรงกันหมายความว่ามีการติดตั้งสำเนาที่ลงนามแตกต่างออกไป

## สัญญา / ตัวอย่าง

```text
403  Forbidden        the site is refusing automated requests
404  Not found        the page moved; the extension is out of date
429  Too many         you have been rate limited, wait before retrying
5xx  Server error     the site itself is broken, nothing to fix locally
1006 / 1020          an IP ban or a firewall rule set by the site owner
Failed to bypass Cloudflare   the anti-bot check could not be cleared
Unable to resolve host / connection failed / timeout   a network problem
CertPathValidatorException / chain validation failed   a bad certificate
Signature mismatch   an APK signed by someone else is already installed
```
