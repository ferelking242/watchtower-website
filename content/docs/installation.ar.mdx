## أندرويد

الهدف الرئيسي، والبناء الوحيد الذي يحصل على كل ميزة أولاً. قم بتنزيل ملف APK للإصدار، أو ملف APK للمعاينة إذا كنت تريد اختبار العمل القادم. تمكين التثبيت من مصادر غير معروفة عندما يطلب Android ذلك، لأن Watchtower لا يتم توزيعه من خلال المتجر.

## سطح المكتب

توجد إصدارات Windows وLinux وmacOS للمشاهدة على شاشة أكبر. قم بإنشائها من المصدر باستخدام Flutter، حيث يتم نشر عناصر الإصدار لنظامي التشغيل Android وLinux CLI أولاً.

## سطر أوامر لينكس

ثنائي واحد بدون نافذة. إنه يدير نفس محرك الامتداد، لذا يمكنه الجلب والبحث والتنزيل على الخادم أو عبر SSH. يقوم برنامج التثبيت بنسخه وملفات وقت التشغيل الخاصة به إلى بادئة تختارها.

## مستقرة أو المعاينة

تعمل إصدارات المعاينة على تتبع أحدث التعليمات البرمجية وتنقطع كثيرًا. احتفظ بالنسخ الاحتياطية التلقائية في حالة تشغيل واحدة، وتوقع إعادة تثبيت إصدار الإصدار في حالة حدوث خطأ ما.

## البناء من المصدر

أنت بحاجة إلى Flutter 3.38 أو أحدث، وDart 3.10 أو أحدث، وسلسلة أدوات Rust. لا يلزمك استخدام الإصدار 1.21 أو الأحدث إلا إذا كنت تريد إعادة بناء خادم التورنت بنفسك.

## ابقها محدثة

يخبرك Watchtower بوجود إصدار جديد، وتقوم بتثبيته بنفس الطريقة التي تم بها تثبيته في المرة الأولى. مكتبتك وإعداداتك تنتقل دون تغيير.

## إذا فشل التثبيت

يتم شرح كل رسائل التثبيت الشائعة في صفحة الأخطاء. يعني عدم تطابق التوقيع أن هناك نسخة موقعة بشكل مختلف مثبتة بالفعل ويجب إزالتها أولاً، ويحتاج التنزيل التالف إلى الجلب مرة أخرى، ويعني عدم تطابق بنية المعالج أنه تم تنزيل الإصدار الخاطئ.

## ملخص سريع

- Android هو النظام الأساسي الوحيد الذي يحتوي على إصدارات منشورة.
- تم تصميم الملف الثنائي بدون رأس لنظام التشغيل Linux x86_64.
- الصدأ مطلوب للبناء من المصدر؛ الذهاب اختياري.
- تشارك عمليات المعاينة وعمليات التثبيت الثابتة نفس البيانات، لذا فإن التبديل يحافظ على مكتبتك.
- قم بإزالة التثبيت المتعارض قبل استبداله بتصميم موقع بشكل مختلف.

## العقد / مثال

```bash
# Android: install the APK
adb install watchtower-release.apk
# Or open the .apk file on the device and allow unknown sources

# Desktop: build from source
flutter pub get
flutter build windows    # or linux, or macos

# Linux server, no screen needed
7z x watchtower-linux-x64-headless.7z -o./watchtower-linux
sudo ./watchtower-linux/install-linux-headless.sh ./watchtower-linux
```
