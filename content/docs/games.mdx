## What a game source is

A game extension lists titles the same way a manga extension lists series, and opens the same browse and search screens.

## Platforms

Games are grouped by platform, which keeps a catalogue navigable when a source covers many systems.

## Browsing and searching

Search fans out across enabled game sources exactly as it does for the other media types, so one query covers all of them.

## Installing game extensions

They install from the same repositories as everything else, and appear under games once installed.

## When nothing is listed

An empty games screen means no game extension is installed. Add a repository that provides one, then refresh.

## Keeping it separate

Game entries do not mix with your reading and watching, so a large games catalogue never clutters your library.

## Cheat sheet

- Game sources install from the same repositories as everything else.
- Games are grouped by platform.
- Search covers every enabled game source at once.
- Game entries stay separate from your library.

## Contract / example

```text
Games
├── Extensions   game sources you have added
├── Platforms    grouped by platform
└── Browse       the same search as other media
```
