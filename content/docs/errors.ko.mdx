## 403 금지됨

웹사이트에서는 귀하의 요청이 자동화된 것으로 판단하여 이를 거부하고 있습니다. 실제로 이는 봇 방지 보호입니다. 먼저 확장 프로그램을 업데이트한 다음 내장 브라우저에서 소스를 한 번 열어 사이트에 있는 모든 검사를 지웁니다. 그래도 거부한다면 해당 출처가 보호 수준을 높였거나 귀하의 주소를 차단했을 수 있습니다.

## 404 찾을 수 없음

예상되는 확장 프로그램이 이동되었거나 제거된 페이지입니다. 이것은 거의 매번 오래된 확장이므로 저장소를 새로 고치고 업데이트하세요. 아직 업데이트가 없다면 확장 작성자가 사이트를 따라잡지 못한 것입니다.

## 429 요청이 너무 많습니다.

너무 빨리 요청하여 속도가 제한되었습니다. 기다리는 것이 실제 해결 방법이며, 업데이트 및 다운로드 실행 빈도를 줄이는 것이 반복을 멈추는 것입니다. 즉시 재시도하면 블록이 확장됩니다.

## 500, 502 및 기타 5xx 오류

웹사이트 자체가 실패하고 있습니다. 기기에 수정할 사항은 없으며, 기다렸다가 나중에 다시 시도하는 것이 올바른 조치입니다. 브라우저에서 사이트를 확인하면 사이트가 모두 다운되었는지 확인할 수 있습니다.

## 1006 및 1020, 방화벽 코드

1006은 일반적으로 임시 IP 금지를 의미하고 1020은 사이트 소유자가 설정한 방화벽 규칙을 의미하며 종종 자국 외부의 방문자를 차단합니다. 네트워크를 변경하면 1006에 도움이 될 수 있습니다. 1020은 일반적으로 해결할 수 없습니다.

## Cloudflare 우회 실패

사이트가 Cloudflare로 보호되고 있으며 자동 검사가 지워지지 않았습니다. 내장된 브라우저에서 소스 페이지를 열고 직접 확인을 완료한 다음 앱으로 돌아옵니다. 페이지가 계속해서 다시 로드되는 경우 문제 해결 페이지를 참조하세요.

## 호스트를 확인할 수 없음, 연결 실패, 시간 초과

이는 소스의 결함이 아니라 네트워크 문제입니다. 기기가 인터넷에 접속되어 있는지 확인하고, 다른 네트워크나 모바일 데이터를 사용해 보고, 설정에서 암호화된 DNS를 활성화하세요. 종속 Wi-Fi 포털이 일반적인 원인입니다.

## 인증서 유효성 검사에 실패했습니다.

사이트의 보안 인증서를 확인할 수 없습니다. 기기 날짜와 시간이 올바른지 확인하고, 앱의 캐시와 쿠키를 지우고, 다른 네트워크를 사용해 보세요. 사이트의 만료된 인증서는 수정할 수 없습니다.

## 저장소 및 SD 카드 오류

카드, 경로 또는 사용할 수 없는 폴더에 대한 메시지는 다운로드 위치가 이동되었거나 읽을 수 없게 되었음을 의미합니다. 여유 공간을 확인하고, 앱에 여전히 해당 폴더에 대한 권한이 있는지 확인하고, 카드에 계속 오류가 발생하면 내부 저장소로 다시 전환하세요.

## 앱 또는 확장 프로그램이 설치되지 않습니다.

다른 사람이 서명한 APK, 잘린 다운로드 및 잘못된 프로세서 아키텍처는 각각 다른 설치 프로그램 메시지를 생성합니다. 충돌하는 복사본을 제거하고 파일을 다시 다운로드한 후 Android에서 알 수 없는 앱을 설치할 수 있는지 확인하세요.

## 오류가 여기에 나열되지 않은 경우

다른 말로 표현하기보다는 정확한 메시지를 복사하세요. 작업 이름과 그 안에 있는 URL은 일반적으로 실패한 단계를 직접 가리키며, 문제 해결 페이지에서는 범위를 좁혀가는 과정을 안내합니다.

## 요약

- 403과 429는 모두 다른 이유로 사이트가 귀하를 거부한다는 것을 의미합니다.
- 404는 거의 항상 업데이트가 필요한 확장입니다.
- 5xx 오류는 장치의 오류가 아닌 웹사이트의 오류입니다.
- 1006은 일시적인 금지입니다. 1020은 우회할 수 없는 방화벽 규칙입니다.
- 정확한 메시지를 복사하세요. 그 안의 URL은 실패한 단계의 이름을 지정합니다.
- 서명 불일치는 다르게 서명된 복사본이 설치되었음을 의미합니다.

## 계약 / 예제

```text
403  Forbidden        the site is refusing automated requests
404  Not found        the page moved; the extension is out of date
429  Too many         you have been rate limited, wait before retrying
5xx  Server error     the site itself is broken, nothing to fix locally
1006 / 1020          an IP ban or a firewall rule set by the site owner
Failed to bypass Cloudflare   the anti-bot check could not be cleared
Unable to resolve host / connection failed / timeout   a network problem
CertPathValidatorException / chain validation failed   a bad certificate
Signature mismatch   an APK signed by someone else is already installed
```
