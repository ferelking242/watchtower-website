## Андроид

Основная цель и единственная сборка, которая получает все функции в первую очередь. Загрузите APK-версию релиза или APK-версию предварительной версии, если хотите протестировать предстоящую работу. Включите установку из неизвестных источников, когда Android попросит, потому что Watchtower не распространяется через магазин.

## Рабочий стол

Существуют сборки для Windows, Linux и macOS для просмотра на большом экране. Создавайте их из исходного кода с помощью Flutter, поскольку артефакты выпуска сначала публикуются для Android и Linux CLI.

## командная строка Linux

Один двоичный файл без окна. Он использует тот же механизм расширений, поэтому может извлекать, искать и загружать на сервер или через SSH. Скрипт установщика копирует его и его файлы времени выполнения в выбранный вами префикс.

## Стабильная или предварительная версия

Предварительные сборки отслеживают новейший код и чаще ломаются. Включите автоматическое резервное копирование, если вы его запустите, и рассчитывайте переустановить сборку выпуска, если что-то пойдет не так.

## Сборка из исходников

Вам понадобится Flutter 3.38 или новее, Dart 3.10 или новее и набор инструментов Rust. Go 1.21 или новее нужен только в том случае, если вы хотите самостоятельно пересобрать торрент-сервер.

## Держите его в курсе

Watchtower сообщает вам, когда существует новая версия, и вы устанавливаете ее так же, как и в первый раз. Ваша библиотека и настройки сохраняются нетронутыми.

## Если установка не удалась

Общие сообщения установщика описаны на странице ошибок. Несоответствие подписи означает, что копия с другой подписью уже установлена ​​и ее необходимо сначала удалить, поврежденную загрузку необходимо загрузить повторно, а несоответствие архитектуры процессора означает, что была загружена неправильная сборка.

## Памятка

- Android — единственная платформа с опубликованными сборками релизов.
- Безголовый двоичный файл создан для Linux x86_64.
- Для сборки из исходного кода требуется Rust; Go не является обязательным.
- Предварительная версия и стабильная версия используют одни и те же данные, поэтому при переключении ваша библиотека сохранится.
- Удалите конфликтующую установку, прежде чем заменять ее сборкой с другой подписью.

## Контракт / пример

```bash
# Android: install the APK
adb install watchtower-release.apk
# Or open the .apk file on the device and allow unknown sources

# Desktop: build from source
flutter pub get
flutter build windows    # or linux, or macos

# Linux server, no screen needed
7z x watchtower-linux-x64-headless.7z -o./watchtower-linux
sudo ./watchtower-linux/install-linux-headless.sh ./watchtower-linux
```
