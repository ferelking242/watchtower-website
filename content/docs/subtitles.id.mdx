## Memilih trek

Jika sebuah episode memuat beberapa trek subtitle, lagu-lagu tersebut akan dicantumkan di lembar subtitle. Pilihan Anda diingat untuk seri itu, jadi Anda hanya memilih satu kali.

## Memperbaiki waktunya

Trek yang berjalan di depan atau di belakang audio dapat didorong sedikit demi sedikit hingga sejajar. Offsetnya diingat, sehingga perbaikan tetap bertahan saat aplikasi dimulai ulang.

## Penataan gaya

Font, ukuran, warna, garis besar dan latar belakang berlaku untuk subtitle teks. Pengaturan ini tidak mempengaruhi video dan aman untuk bereksperimen dengan pertengahan episode.

## File Anda sendiri

Letakkan file subtitle di sebelah episode lokal dengan nama yang cocok dan pemutar akan memuatnya secara otomatis, tanpa mengubah pengaturan.

## Subtitle dimasukkan ke dalam gambar

Beberapa subtitle berupa gambar, bukan teks. Mereka tidak dapat dibenahi, hanya diposisikan ulang atau diubah ukurannya, karena penataan gaya adalah bagian dari gambar itu sendiri.

## Ketika subtitle tidak muncul

Periksa lembar subtitle terlebih dahulu: sumber mungkin tidak menawarkan apa pun, atau nama file mungkin tidak cukup cocok dengan episode untuk dipasangkan.

## Ringkasan

- Subtitle teks dapat diubah gayanya; subtitle gambar tidak bisa.
- Offset waktu disimpan dan bertahan saat restart.
- File yang cocok di samping episode lokal dimuat dengan sendirinya.
- Pilihan subtitle diingat per seri.

## Kontrak / contoh

```text
# Where a subtitle can come from
1. a track bundled inside the stream
2. a file sitting next to the episode on disk
3. a track the source downloads for you
4. a file you pick by hand
```
