## トラックを選択する

エピソードに複数の字幕トラックが含まれる場合、それらは字幕シートにリストされます。あなたの選択はそのシリーズに対して記憶されるため、選択するのは 1 回だけです。

## タイミングを修正する

オーディオの前または後ろにあるトラックは、整列するまで少しずつ移動できます。オフセットは記憶されているため、アプリを再起動しても修正は有効です。

## スタイリング

フォント、サイズ、色、輪郭、背景がテキスト字幕に適用されます。これらの設定はビデオには影響しないため、エピソードの途中で安全に試すことができます。

## 自分のファイル

一致する名前を持つローカル エピソードの隣に字幕ファイルを配置すると、設定を変更することなく、プレーヤーがそのファイルを自動的に読み込みます。

## 画像に焼き付けられた字幕

一部の字幕はテキストではなく画像です。スタイルは画像自体の一部であるため、スタイルを変更することはできません。位置またはサイズの変更のみが可能です。

## 字幕が表示されないときは

まずサブタイトル シートを確認してください。ソースにサブタイトル シートがないか、ファイル名がエピソードとペアにできるほど一致していない可能性があります。

## 早見表

- テキスト字幕のスタイルは変更できます。画像字幕はできません。
- タイミング オフセットは保存され、再起動後も存続します。
- ローカル エピソードの横にある一致するファイルは、自動的にロードされます。
- 字幕の選択はシリーズごとに記憶されます。

## 契約 / 例

```text
# Where a subtitle can come from
1. a track bundled inside the stream
2. a file sitting next to the episode on disk
3. a track the source downloads for you
4. a file you pick by hand
```
