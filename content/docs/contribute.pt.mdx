## Maneiras de ajudar

Relate bugs com a mensagem exata que você viu, melhore uma fonte, escreva uma extensão para um site que ninguém cobriu ou traduza esse site para outro idioma.

## Trabalhando no aplicativo

Clone o repositório, instale as cadeias de ferramentas Flutter e Rust e execute o analisador antes de abrir uma solicitação pull. Go só é necessário se você estiver alterando o servidor de torrent.

## Trabalhando na documentação

O site é seu próprio repositório. Adicionar um idioma significa adicionar um arquivo de tradução; o layout e a navegação já cuidam do resto.

## Traduzindo

O aplicativo e este site vêm em vários idiomas, e um novo é aditivo. Você nunca precisa tocar no design para adicionar seu próprio idioma.

## Relatando um bom bug

Inclua a versão do seu aplicativo, a fonte que você estava usando, o texto exato do erro e se outras fontes ainda funcionam. Isso geralmente é suficiente para localizar a falha.

## Antes de uma grande mudança

Abra um problema ou pergunte no Discord primeiro. Isso evita que você construa algo que não se ajusta ao rumo do projeto.

## Resumo

- A documentação é um repositório separado do aplicativo.
- Adicionar um idioma significa adicionar um arquivo, não alterar o layout.
- Relatar o texto exato do erro economiza muito tempo.
- A ferrugem é necessária para o funcionamento do aplicativo; Vá apenas para o servidor torrent.
