## 它的用途是什么

服务器、SSH 会话和自动化作业。它与具有文本界面而不是屏幕的应用程序具有相同的扩展引擎，因此不需要图形会话。

## 确定方向

从 help 命令开始，然后运行 ​​doctor 命令以确认运行时可以加载并达到其所需的一切，然后再信任它执行作业。

## 使用扩展

列出存储库提供的内容，对其进行验证，并根据实时站点测试源。测试分阶段运行，从简单地加载源代码到执行其搜索和详细信息调用。

## 直接调用源

您可以调用单个操作（例如搜索）并返回 JSON。这就是命令行对于编写脚本和调试源代码非常有用的原因。

## 通过网络提供服务

它可以启动应用程序公开的同一个 Web 服务器，这就是远程客户端与无头机器对话的方式。

## 它还没有做什么

库、历史记录和下载队列命令不可无头使用，因为命令行不会打开应用程序的本地数据库。那些仍然需要该应用程序。

## 速查表

- 命令行重用应用程序的扩展引擎。
- doctor 命令会在您依赖它之前检查运行时。
- 源可以从加载到搜索分阶段进行测试。
- 库和下载命令仍然需要该应用程序。

## 契约 / 示例

```bash
watchtower --cli help
watchtower --cli doctor --json
watchtower --cli extensions list --repo ./my-repo
watchtower --cli extensions test --repo ./my-repo --mode smoke
watchtower --cli source 1900000002 search --query "space opera" --json
```
