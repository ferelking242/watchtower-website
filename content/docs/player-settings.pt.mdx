## Decodificação

A decodificação de hardware é mais rápida e leve com a bateria e serve para quase tudo. Mude para software quando um arquivo específico for reproduzido mal, pois a decodificação de software perdoa mais codecs incomuns.

## Gestos

Decida qual deslizar faz o quê: vertical para brilho e volume, horizontal para busca. Cada direção pode ser invertida se parecer invertida para você.

## Botões personalizados

Adicione as ações que você mais utiliza, como pular uma introdução ou fazer uma captura de tela, diretamente na superfície do player para que não fiquem enterradas nos menus.

## Reprodução avançada

O tamanho do buffer, uma proporção forçada e picture-in-picture estão aqui para os raros casos em que o comportamento automático não é o que você deseja. A maioria das pessoas nunca precisa tocá-los.

## Exceções por série

Quase todas as configurações do jogador podem ser substituídas para uma única série sem alterar os padrões de todo o resto. Útil para um programa com áudio estranho.

## Depois de um backup das configurações

Botões personalizados e preferências do player viajam em seu arquivo de backup, portanto, a restauração em um novo dispositivo traz consigo o layout do player.

## Resumo

- A decodificação de hardware é o padrão e é adequada para a maioria dos arquivos.
- Cada direção do gesto pode ser invertida ou desativada.
- As configurações podem ser substituídas para uma única série.
- As preferências do jogador estão incluídas em um backup.

## Contrato / exemplo

```text
Decoder        hardware · software · automatic
Gestures       brightness · volume · seek
Subtitles      font · size · delay
Custom buttons the actions you use most
Advanced       buffer · aspect ratio · picture-in-picture
```
