## 拡張機能を実行するもの

Watchtower は、アプリに埋め込まれた小さな JavaScript エンジンを使用します。これはどのプラットフォームでも同じエンジンであるため、ソースは電話でもサーバーでも同じように動作します。

## 拡張機能でできること

Web リクエストを作成し、受信したページを解析し、独自の設定のいくつかを保持できます。それがツールボックス全体です。

## 遠ざけられているもの

ファイル、ライブラリ、アカウント、アプリ自体の画面。拡張機能が生成するものはすべて、アプリがレンダリングするためのプレーン データとして返されます。

## 遅いソースが長引く理由

ソースの応答が遅いと、アプリがそれを待つため、ソース自体の画面が遅くなります。他のソースは影響を受けないため、速度が遅い場合は、重いアプリではなく、1 つの悪いソースの兆候です。

## これが信頼にとって何を意味するか

サンドボックスは拡張機能が破壊できるものを制限しますが、意図を判断するものではありません。入力したものや取得したものはすべて表示されます。信頼できる人からインストールしてください。

## どこでも同じエンジン

アプリと Linux コマンド ラインはこのランタイムを共有するため、携帯電話で動作する拡張機能は、変更を加えることなくサーバーでも動作します。

## 早見表

- 拡張機能はネットワーク アクセスとページ解析を行うだけで、それ以外は何も行いません。
- ファイルやライブラリを直接読み取ることはできません。
- 1 つの遅いソースは、それ自身の画面のみを遅くします。
- 同じサンドボックスがモバイル、デスクトップ、コマンド ラインで実行されます。
