## Lectura

Establezca el modo predeterminado, si las páginas se animan a medida que pasan y qué capítulos omitir. Los capítulos omitidos siguen ahí, simplemente no te interrumpen.

## Mostrar

El bloqueo de rotación, el color de fondo y la pantalla completa conviven aquí. Un fondo oscuro favorece la lectura nocturna y reduce el brillo entre las páginas.

## paginas

Elija cómo una página llena la pantalla: ajuste el ancho, la altura, toda la pantalla o muéstrela en su tamaño original. El recorte de bordes recorta los márgenes de escaneo automáticamente.

## Toque zonas

Elija dónde al tocar la página avanza, retrocede y abre el menú. Todo el diseño se puede reflejar para leer con la mano izquierda.

## tira larga

El acolchado lateral y las zonas táctiles separadas hacen que los webtoons altos sean cómodos en una pantalla ancha, donde de otro modo una imagen de ancho completo sería demasiado pequeña.

## Excepciones por serie

Cualquiera de estos puede anularse para una serie, lo cual resulta útil para un título que se escaneó de manera inusual o se lee en la otra dirección.

## Chuleta

- Las opciones de escala incluyen ancho de ajuste, altura de ajuste, pantalla de ajuste y tamaño original.
- El recorte de bordes elimina los márgenes de escaneo.
- Las zonas de toque se pueden reflejar para la lectura de zurdos.
- Las reglas de omisión se pueden anular por serie.
