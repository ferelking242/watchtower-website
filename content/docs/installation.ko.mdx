## 기계적 인조 인간

주요 대상이자 모든 기능을 먼저 얻는 유일한 빌드입니다. 출시 APK를 다운로드하거나, 향후 작업을 테스트하려면 미리보기 APK를 다운로드하세요. Watchtower는 스토어를 통해 배포되지 않으므로 Android에서 요청할 때 알 수 없는 소스에서 설치를 활성화합니다.

## 데스크탑

더 큰 화면에서 시청하기 위한 Windows, Linux 및 macOS 빌드가 존재합니다. 릴리스 아티팩트는 Android 및 Linux CLI용으로 먼저 게시되므로 Flutter를 사용하여 소스에서 빌드하세요.

## 리눅스 명령줄

창이 없는 단일 바이너리입니다. 동일한 확장 엔진을 실행하므로 서버나 SSH를 통해 가져오고 검색하고 다운로드할 수 있습니다. 설치 프로그램 스크립트는 해당 스크립트와 해당 런타임 파일을 선택한 접두사에 복사합니다.

## 안정 또는 미리보기

미리보기 빌드는 최신 코드를 추적하고 더 자주 중단됩니다. 실행하는 경우 자동 백업을 유지하고 문제가 발생하면 릴리스 빌드를 다시 설치해야 합니다.

## 소스에서 빌드

Flutter 3.38 이상, Dart 3.10 이상 및 Rust 툴체인이 필요합니다. Go 1.21 이상은 토렌트 서버를 직접 재구축하려는 경우에만 필요합니다.

## 계속 업데이트하세요

Watchtower는 새 버전이 존재하면 알려주며, 처음과 동일한 방식으로 설치합니다. 라이브러리와 설정은 그대로 유지됩니다.

## 설치에 실패한 경우

일반적인 설치 프로그램 메시지는 각각 오류 페이지에 설명되어 있습니다. 서명 불일치는 다르게 서명된 복사본이 이미 설치되어 있으므로 먼저 제거해야 함을 의미하고, 손상된 다운로드를 다시 가져와야 하며, 프로세서 아키텍처 불일치는 잘못된 빌드가 다운로드되었음을 의미합니다.

## 요약

- Android는 릴리스 빌드가 게시된 유일한 플랫폼입니다.
- 헤드리스 바이너리는 Linux x86_64용으로 빌드되었습니다.
- Rust는 소스에서 빌드해야 합니다. 이동은 선택사항입니다.
- 미리보기 및 안정적인 설치는 동일한 데이터를 공유하므로 전환하면 라이브러리가 유지됩니다.
- 충돌하는 설치를 제거한 후 다르게 서명된 빌드로 교체하세요.

## 계약 / 예제

```bash
# Android: install the APK
adb install watchtower-release.apk
# Or open the .apk file on the device and allow unknown sources

# Desktop: build from source
flutter pub get
flutter build windows    # or linux, or macos

# Linux server, no screen needed
7z x watchtower-linux-x64-headless.7z -o./watchtower-linux
sudo ./watchtower-linux/install-linux-headless.sh ./watchtower-linux
```
