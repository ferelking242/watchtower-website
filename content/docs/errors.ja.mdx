## 403 禁止

ウェブサイトはあなたのリクエストが自動化されていると判断し、リクエストを拒否しています。実際には、これはボット対策です。まず拡張機能を更新してから、内蔵ブラウザでソースを一度開いて、サイトが保持しているチェックをクリアします。それでも拒否される場合は、送信元が保護を強化したか、アドレスをブロックしている可能性があります。

## 404 見つかりません

拡張機能が予期していたページが移動または削除されました。これはほぼ毎回古い拡張機能なので、リポジトリを更新して更新してください。まだ更新がない場合は、拡張機能の作成者がサイトに追いついていません。

## 429 リクエストが多すぎます

リクエストが速すぎるため、レートが制限されています。実際の解決策は待つことであり、更新とダウンロードの実行頻度を減らすことで再発を防ぐことができます。すぐに再試行するとブロックが拡張されるだけです。

## 500、502、およびその他の 5xx エラー

ウェブサイト自体が失敗しています。デバイスには修正すべき点は何もないため、しばらく待ってからもう一度試してみるのが正しい対処です。ブラウザでサイトをチェックすると、全員がダウンしているかどうかが確認されます。

## 1006 および 1020、ファイアウォール コード

1006 は通常、一時的な IP 禁止を意味し、1020 はサイト所有者によって設定されたファイアウォール ルールを意味し、多くの場合、国外からの訪問者をブロックします。ネットワークを変更すると 1006 を解決できる場合があります。通常、1020 を回避することはできません。

## Cloudflareのバイパスに失敗しました

サイトは Cloudflare によって保護されており、自動チェックがクリアされませんでした。内蔵ブラウザでソースのページを開き、手動で検証を完了してから、アプリに戻ります。ページが際限なくリロードされる場合は、トラブルシューティング ページを参照してください。

## ホストを解決できない、接続失敗、タイムアウト

これらは、ソースの障害ではなく、ネットワークの問題です。デバイスがインターネットにアクセスできることを確認し、別のネットワークまたはモバイル データを試し、設定で暗号化された DNS を有効にします。キャプティブ Wi-Fi ポータルが一般的な原因です。

## 証明書の検証に失敗しました

サイトのセキュリティ証明書を検証できませんでした。デバイスの日付と時刻が正しいことを確認し、アプリのキャッシュと Cookie をクリアして、別のネットワークを試してください。サイト上の期限切れの証明書は修正できません。

## ストレージとSDカードのエラー

カード、パス、または使用できないフォルダーに関するメッセージは、ダウンロード場所が移動したか、読み取り不能になったことを意味します。空き容量をチェックし、アプリがそのフォルダーに対するアクセス許可をまだ持っていることを確認し、カードが引き続き失敗する場合は内部ストレージに切り替えます。

## アプリまたは拡張機能がインストールされない

他人によって署名された APK、切り詰められたダウンロード、および間違ったプロセッサ アーキテクチャにより、それぞれ異なるインストーラー メッセージが生成されます。競合するコピーを削除してファイルを再度ダウンロードし、Android で不明なアプリのインストールが許可されていることを確認してください。

## ここに記載されていないエラーの場合

メッセージを言い換えるのではなく、正確にコピーしてください。通常、操作名とその中の URL は失敗したステップを直接示しており、トラブルシューティング ページではそのステップが絞り込まれます。

## 早見表

- 403 と 429 は両方とも、さまざまな理由でサイトがユーザーを拒否していることを意味します。
- 404 は、ほとんどの場合、更新が必要な拡張機能です。
- 5xx エラーは Web サイトのせいであり、デバイスのせいではありません。
- 1006 は一時的な禁止です。 1020 はバイパスできないファイアウォール ルールです。
- メッセージをそのままコピーします。メッセージ内の URL は、失敗したステップの名前です。
- 署名の不一致は、異なる署名のコピーがインストールされていることを意味します。

## 契約 / 例

```text
403  Forbidden        the site is refusing automated requests
404  Not found        the page moved; the extension is out of date
429  Too many         you have been rate limited, wait before retrying
5xx  Server error     the site itself is broken, nothing to fix locally
1006 / 1020          an IP ban or a firewall rule set by the site owner
Failed to bypass Cloudflare   the anti-bot check could not be cleared
Unable to resolve host / connection failed / timeout   a network problem
CertPathValidatorException / chain validation failed   a bad certificate
Signature mismatch   an APK signed by someone else is already installed
```
