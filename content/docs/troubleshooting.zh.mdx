## 首先缩小范围

在触摸任何设置之前，请确定问题是出在来源、您的网络还是您的设备上。一个来源发生故障，而其他来源则指向该来源；一切故障都出在应用程序或连接上。

## 首先更新所有内容

刷新您的存储库并安装所有扩展更新，然后检查应用程序更新。很大一部分突然损坏是网站发生了变化以及扩展程序已经修复但尚未安装。

## 源停止工作

这是最常见的问题，通常也是最不严重的问题。网站发生了变化，扩展需要更新，刷新您的存储库即可解决。如果还没有更新，则扩展作者还没有跟上。

## 根本没有加载任何东西

如果每个来源都失败，请改为查看网络。在设置中尝试移动数据、另一个 Wi-Fi 网络和加密 DNS。一个常见的原因是单个网络阻止了所有内容，或者未登录的强制门户。

## 打开网站以通过检查

有些网站在回答之前会进行验证。从“浏览”中打开源代码，并使用内置浏览器加载站点自己的页面，手动完成所有检查，然后将其关闭并返回到应用程序。执行此操作一次通常可以清除该来源的障碍。

## Cloudflare 和无限重新加载

Cloudflare 背后的网站可以不断重新加载其检查，而不是让您通过。尝试再次在内置浏览器中打开该网站，在高级设置中更改用户代理，或等待该网站降低其保护。有些来源故意难以从应用程序中使用。

## 清除 cookie 和网络数据

这将重置应用程序存储的浏览状态，包括任何登录信息。这是对卡住的检查的正确修复，并且在确定源已失效之前值得这样做。如果来源需要帐户，您随后需要重新登录。

## 更改您的用户代理

用户代理是向网站标识您的设备的字符串，有些网站将其视为机器人信号。用通用浏览器字符串替换默认值，然后重新启动应用程序，有时会通过检查，否则会循环。

## 扩展将不会安装

默认情况下，Android 会阻止来自商店外部的安装。允许您的文件管理器或浏览器使用它，如果缺少该选项，请使用 Shizuku 作为替代途径。下载中途停止会产生不同的消息，因此请从头开始重新安装。

## 内容在错误的位置打开

如果漫画在视频播放器中打开，或剧集在阅读器中打开，则扩展程序会声明错误的内容类型。这是扩展程序中的错误，而不是您的设置中的错误，因此请报告它而不是尝试在本地修复它。

## 获取崩溃日志和更多详细信息

高级设置可以转储崩溃日志，并且从设备捕获的 logcat 可以更深入地显示应用程序正在执行的操作。当您报告问题时，两者都值得附加，因为它们将模糊的描述变成可以追踪的内容。

## 存储和读取缓慢或滞后

加载缓慢通常是网站、您的连接或速率限制而不是应用程序。阅读缓慢来自于章节中过大的图像。切换源、释放内存或等待速率限制是实际的修复方法。

## 当不只是你一个人的时候

如果其他人看到同样的失败，则问题是扩展或应用程序而不是您的设置。在打开新报告之前，请检查项目的问题跟踪器以查找来源，并包含您的应用程序版本和确切的错误文本。

## 速查表

- 一个损坏的源几乎总是源，而不是应用程序。
- 陈旧的扩展是突然断裂的最常见原因。
- 如果每个源都出现故障，请先怀疑网络，然后再怀疑应用程序。
- 在内置浏览器中打开站点可以清除许多验证检查。
- 清除 cookie 和网络数据会重置卡住的检查和所有登录。
- 崩溃日志和 logcat 使错误报告可追踪。

## 契约 / 示例

```text
# Narrow it down before changing anything
Does the site load in a browser?     if no, it is the source
Does another source work right now?  if yes, it is one source
Does the app work on mobile data?    if yes, it is your network

Then:  update the extension → open the site in the built-in browser
       → clear cookies and web data → check permissions
```
