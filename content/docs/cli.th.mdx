## มันมีไว้เพื่ออะไร

เซิร์ฟเวอร์ เซสชัน SSH และงานอัตโนมัติ มันเป็นเอ็นจิ้นส่วนขยายเดียวกันกับแอปที่มีอินเทอร์เฟซข้อความแทนที่จะเป็นหน้าจอ ดังนั้นจึงไม่จำเป็นต้องมีเซสชันกราฟิก

## เริ่มมีความมุ่งมั่น

เริ่มต้นด้วยคำสั่ง help จากนั้นรันคำสั่งแพทย์เพื่อยืนยันว่ารันไทม์สามารถโหลดและเข้าถึงทุกสิ่งที่ต้องการได้ก่อนที่คุณจะเชื่อถืองานนั้น

## การทำงานกับส่วนขยาย

แสดงรายการสิ่งที่พื้นที่เก็บข้อมูลนำเสนอ ตรวจสอบ และทดสอบแหล่งที่มากับไซต์ที่ใช้งานอยู่ การทดสอบดำเนินการเป็นขั้นตอน ตั้งแต่การโหลดแหล่งที่มาไปจนถึงการดำเนินการค้นหาและการเรียกรายละเอียด

## โทรไปยังแหล่งที่มาโดยตรง

คุณสามารถเรียกใช้การดำเนินการเดียว เช่น การค้นหา และรับ JSON กลับมา นั่นคือสิ่งที่ทำให้บรรทัดคำสั่งมีประโยชน์สำหรับการเขียนสคริปต์และการดีบักแหล่งที่มา

## ให้บริการผ่านเครือข่าย

มันสามารถเริ่มต้นเว็บเซิร์ฟเวอร์เดียวกันกับที่แอปเปิดเผย ซึ่งเป็นวิธีที่ไคลเอนต์ระยะไกลสื่อสารกับเครื่องที่ไม่มีหัว

## อะไรที่ยังไม่ได้ทำ

คำสั่งไลบรารี ประวัติ และคิวดาวน์โหลดไม่สามารถใช้งานได้แบบ headless เนื่องจากบรรทัดคำสั่งไม่ได้เปิดฐานข้อมูลในเครื่องของแอป ผู้ที่ยังต้องการแอป

## สรุปย่อ

- บรรทัดคำสั่งนำกลไกส่วนขยายของแอปกลับมาใช้ใหม่
- คำสั่งแพทย์จะตรวจสอบรันไทม์ก่อนที่คุณจะเชื่อถือ
- แหล่งที่มาสามารถทดสอบได้ในขั้นตอนต่างๆ ตั้งแต่การโหลดไปจนถึงการค้นหา
- คำสั่งไลบรารีและการดาวน์โหลดยังคงต้องใช้แอป

## สัญญา / ตัวอย่าง

```bash
watchtower --cli help
watchtower --cli doctor --json
watchtower --cli extensions list --repo ./my-repo
watchtower --cli extensions test --repo ./my-repo --mode smoke
watchtower --cli source 1900000002 search --query "space opera" --json
```
