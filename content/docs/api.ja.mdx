## それは何ですか

アプリに組み込まれた小さな Web サーバー。インターフェイスと同じ拡張機能と同じライブラリを使用するため、返されるものはすべて画面に表示されるものと一致します。

## オンにする

意図的に有効にするまではオフになります。詳細設定でスイッチをオンにしてポートをメモし、ツールをそのアドレスに向けます。

## 質問できること

インストールされているソース、ライブラリ エントリ、任意のソースに対する検索、および解決されたビデオ ストリーム。メディア センターや外部プレーヤーを駆動するには十分です。

## なぜそれを欲しがるのか

自動化、別のフロントエンド、または電話機がすでに設定しているソースをネットワーク上の別のデバイスに使用させる。

## 自分のネットワーク上に保管しておいてください

サーバーにはパスワードがなく、信頼できるローカル ネットワーク用です。誰もがあなたのライブラリを読むことができるインターネットに公開しないでください。

## コマンドラインとの関係

Linux コマンド ラインは同じサーバーを公開するため、アプリに対して作成されたスクリプトは、変更を加えることなくヘッドレス マシンに対して機能します。

## 早見表

- 設定で有効にするまで、サーバーはオフになります。
- デフォルトではポート 4567 で待機します。
- インターフェイスと同じソースとライブラリを使用します。
- これは、インターネットではなく、信頼できるローカル ネットワークを対象としています。

## 契約 / 例

```text
# Turn it on first, in settings
Settings → Advanced → Enable the server
# It then answers on port 4567
http://localhost:4567

GET  /sources     the sources you have installed
GET  /library     the entries in your library
POST /search      search a source
GET  /stream      resolve a video stream
```
