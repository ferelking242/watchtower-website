## 为什么应用商店里没有它？

因为 Watchtower 在运行时安装扩展，而存储策略不允许。这也是为什么每次安装都来自您选择信任的 APK。

## 有iOS版本吗？

底层代码是跨平台的，但在 iOS 上的发布受到平台规则的限制，不予承诺。 Android 是一个一切皆为先的平台。

## 没有互联网也能工作吗？

您下载的任何内容以及本地文件都可以完全离线工作。浏览源和搜索不需要，因为它们需要网站本身。

## 我可以在设备之间同步吗？

没有自动同步。您使用备份文件移动库，并且必须单独复制下载的媒体。

## 它合法且免费吗？

Watchtower 是免费且开源的，并且不包含自己的内容。您通过扩展添加的内容是您的责任，这就是为什么该应用程序谨慎地说它不会审查它们。

## 为什么我看不到已安装的源？

两个过滤器隐藏源而不删除它们。如果扩展程序提供的语言不是您设备的语言，请在源列表过滤器中打开该语言。如果是成人来源，请启用在列表中显示 NSFW 来源的选项。

## 如何卸载扩展？

从扩展程序屏幕卸载它，或者像 Android 设置中的任何其他应用程序一样卸载它。您的图书馆条目保持不变，只是显示为不可用，直到另一个来源可以提供它们。

## 为什么我的下载不显示？

按文件夹检测下载。如果存储位置移动、SD 卡被移除或者源或系列在网站上被重命名，则应用程序无法匹配该文件夹。修复位置或重命名文件夹以匹配，然后重建下载索引。

## 为什么我的照片库显示封面和剧集？

该应用程序通常使用 .nomedia 文件从系统库中隐藏其媒体。如果没有，请自行创建一个并将其放入下载文件夹中，或者放入本地源文件夹中（如果泄漏的是本地源文件夹）。

## 为什么读取或加载速度很慢？

加载缓慢是网站、您的连接或速率限制，而不是应用程序太重。阅读缓慢来自于章节中过大的图像，因此请释放内存或选择扫描较小的来源。

## 为什么有些剧集不显示？

除了网络问题之外，应用程序有时可能会错过视频的存在。离开播放器并再次打开剧集通常会注册它。

## 为什么库更新会跳过条目？

有意跳过包含未观看或未读内容的条目、尚未开始的条目、标记为已完成的条目以及没有预期发布的条目。这可以防止大型图书馆破坏源代码并阻止应用程序被屏蔽。

## 为什么库更新会在后台停止？

一些 Android 版本会积极节省电池并暂停后台工作。如果更新仅在您打开应用程序时到达，则免除 Watchtower 的电池优化。

## 为什么截图会被阻止？

在任务切换器中隐藏应用程序的隐私设置也会阻止屏幕截图。如果您想捕获屏幕，请关闭该设置。

## 有东西坏了，现在怎么办？

首先更新您的扩展，因为这可以修复大多数损坏。如果问题仍然存在，请检查错误页面以获取您所看到的确切消息，然后检查故障排除页面，然后再假设应用程序出现故障。

## 速查表

- Watchtower 不通过应用程序商店分发。
- 下载的内容和本地文件完全离线工作。
- 设备之间没有自动同步。
- 隐藏源通常是语言过滤器或 NSFW 切换开关。
- 下载内容与文件夹名称匹配，因此重命名会隐藏它。
- 更新扩展修复了大多数突然的损坏。

## 契约 / 示例

```text
Is it on a store?        No. Installable extensions conflict with store rules.
Is there an iOS build?   The code supports it; shipping it is not promised.
Does it work offline?    Downloads and local files do, browsing does not.
Does it sync?            No. Move your library with a backup file.
Is it free?              Yes, and the source is open under Apache 2.0.

Missing sources?   check the language filter and the NSFW toggle
Missing downloads? check the storage folder and rebuild the index
```
