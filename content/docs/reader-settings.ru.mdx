## Чтение

Установите режим по умолчанию, анимируйте ли страницы при перелистывании и какие главы следует пропускать. Пропущенные главы все равно есть, они вас просто не отвлекают.

## Отображать

Блокировка вращения, цвет фона и полноэкранный режим здесь сочетаются друг с другом. Темный фон подходит для чтения ночью и уменьшает блики между страницами.

## Страницы

Выберите, как страница будет заполнять экран: подогнать ширину, высоту, весь экран или показать ее в исходном размере. Обрезка границ автоматически обрезает поля сканирования.

## Коснитесь зон

Выберите, где нажатие переворачивает страницу вперед, назад и открывает меню. Весь макет можно отразить для чтения левой рукой.

## Длинная полоса

Боковые отступы и отдельные зоны касания делают высокие вебтуны удобными на широком экране, где в противном случае изображение во всю ширину было бы слишком маленьким.

## Исключения для каждой серии

Любое из них можно переопределить для одной серии, что удобно для заголовков, которые сканировались необычно или читались в другом направлении.

## Памятка

- Параметры масштаба включают ширину, высоту, экран и исходный размер.
- Обрезка границ удаляет поля сканирования.
- Зоны касания можно зеркально отразить для чтения левой рукой.
- Правила пропуска можно переопределить для каждой серии.
