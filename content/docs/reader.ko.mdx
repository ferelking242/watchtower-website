## 읽기 모드 선택

페이지 모드는 인쇄된 만화에 적합하고, 긴 스트립은 하나의 긴 이미지로 그려진 웹툰에 적합합니다. 기본값을 설정하고 제목이 다른 방향으로 더 잘 읽힐 때 시리즈별로 변경합니다.

## 페이지 넘기기

가장자리를 탭하여 앞이나 뒤로 이동하고, 스와이프하여 긴 스트립으로 스크롤하고, 핀치하여 확대/축소합니다. 가운데를 탭하면 페이지를 떠나지 않고 메뉴가 열립니다.

## 중단한 부분부터 다시 시작

Watchtower는 각 장에서 도달한 페이지를 기억하므로 시리즈를 다시 열면 시작 부분이 아닌 정확히 중지한 위치로 이동합니다.

## 넓은 페이지 및 스프레드

두 페이지로 된 스프레드와 비정상적으로 넓은 스캔은 분할, 회전 또는 크기 조정이 가능하므로 휴대폰에서 읽을 수 없습니다.

## 다운로드한 챕터

다운로드한 장은 즉시 열리고 챕터 목록에 표시되므로 오프라인에서 읽을 수 있습니다.

## 짧은 이야기

텍스트 소설은 라이브러리의 동일한 항목을 사용하지만 확장 프로그램의 콘텐츠 유형에서 자동으로 선택된 이미지 뷰어 대신 텍스트 리더에서 열립니다.

## 페이지가 로드되지 않는 경우

때때로 앱이 장의 이미지를 인식하지 못하는 경우가 있습니다. 리더를 종료하고 장을 다시 열면 일반적으로 문제가 해결되며, 문제가 지속되면 앱이 아닌 소스에서 이미지 자체가 누락됩니다.

## 한 번에 두 페이지

스캔 시 페이지 나누기 위치가 거의 일치하지 않으므로 이중 페이지 리더를 사용할 수 없습니다. 한 번에 한 페이지씩 읽거나 웹툰의 경우 긴 스트립을 사용하는 것이 현재의 행동입니다.

## 요약

- 긴 스트립은 세로형 웹툰에 적합하며 페이지 너비를 무시합니다.
- 독자는 각 장별로 도달한 페이지를 기억합니다.
- 확대/축소는 켤 때까지 긴 스트립에서 꺼져 있습니다.
- 소설은 이미지 리더가 아닌 텍스트 리더에서 열립니다.
- 장을 다시 열면 로드에 실패한 페이지가 수정됩니다.
