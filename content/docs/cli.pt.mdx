## Para que serve

Servidores, sessões SSH e trabalhos automatizados. É o mesmo mecanismo de extensão do aplicativo com uma interface de texto em vez de telas, portanto não precisa de sessão gráfica.

## Orientando-se

Comece com o comando help e, em seguida, execute o comando doctor para confirmar se o tempo de execução pode carregar e alcançar tudo o que precisa antes de confiar nele para um trabalho.

## Trabalhando com extensões

Liste o que um repositório oferece, valide-o e teste uma fonte no site ativo. O teste é executado em etapas, desde o simples carregamento do código-fonte até o exercício de sua pesquisa e chamadas detalhadas.

## Ligar diretamente para uma fonte

Você pode invocar uma única operação, como uma pesquisa, e recuperar o JSON. É isso que torna a linha de comando útil para scripts e para depuração de uma fonte.

## Servindo pela rede

Ele pode iniciar o mesmo servidor web que o aplicativo expõe, que é como um cliente remoto se comunica com uma máquina sem cabeça.

## O que ainda não faz

Os comandos de biblioteca, histórico e fila de download não estão disponíveis sem comando, porque a linha de comando não abre os bancos de dados locais do aplicativo. Eles ainda precisam do aplicativo.

## Resumo

- A linha de comando reutiliza o mecanismo de extensão do aplicativo.
- O comando doctor verifica o tempo de execução antes de você confiar nele.
- Uma fonte pode ser testada em etapas, desde o carregamento até a pesquisa.
- Os comandos de biblioteca e download ainda exigem o aplicativo.

## Contrato / exemplo

```bash
watchtower --cli help
watchtower --cli doctor --json
watchtower --cli extensions list --repo ./my-repo
watchtower --cli extensions test --repo ./my-repo --mode smoke
watchtower --cli source 1900000002 search --query "space opera" --json
```
